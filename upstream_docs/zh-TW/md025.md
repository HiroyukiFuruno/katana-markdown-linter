# `MD025` - 同一文件中只能有一個頂層標題

標籤: `headings`

別名: `single-h1`, `single-title`

參數:

- `front_matter_title`: 設定值 (`string`, 預設值 `^\s*title\s*[:=]`)
- `level`: 設定值 (`integer`, 預設值 `1`)

## 概覽

同一文件中只能有一個頂層標題。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# Top level heading

# Another top-level heading
```

```markdown
# Title

## Heading

## Another heading
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
