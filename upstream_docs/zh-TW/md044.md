# `MD044` - 專有名詞寫法應符合設定

標籤: `spelling`

別名: `proper-names`

參數:

- `code_blocks`: 設定值 (`boolean`, 預設值 `true`)
- `html_elements`: 設定值 (`boolean`, 預設值 `true`)
- `names`: 設定值 (`string[]`, 預設值 `[]`)

## 概覽

專有名詞寫法應符合設定。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```json
[
    "JavaScript"
]
```

```json
[
    "GitHub",
    "github.com"
]
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
