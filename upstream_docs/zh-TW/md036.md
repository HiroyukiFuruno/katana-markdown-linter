# `MD036` - 不要用只有強調的行取代標題

標籤: `emphasis`, `headings`

別名: `no-emphasis-as-heading`

參數:

- `punctuation`: 設定值 (`string`, 預設值 `.,;:!?。，；：！？`)

## 概覽

不要用只有強調的行取代標題。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
**My document**

Lorem ipsum dolor sit amet...

_Another section_

Consectetur adipiscing elit, sed do eiusmod.
```

```markdown
# My document

Lorem ipsum dolor sit amet...

## Another section

Consectetur adipiscing elit, sed do eiusmod.
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
