# `MD030` - 清單標記後的空格數應一致

標籤: `ol`, `ul`, `whitespace`

別名: `list-marker-space`

參數:

- `ol_multi`: 設定值 (`integer`, 預設值 `1`)
- `ol_single`: 設定值 (`integer`, 預設值 `1`)
- `ul_multi`: 設定值 (`integer`, 預設值 `1`)
- `ul_single`: 設定值 (`integer`, 預設值 `1`)

## 概覽

清單標記後的空格數應一致。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
* Foo
* Bar
* Baz

1. Foo
1. Bar
1. Baz

1. Foo
   * Bar
1. Baz
```

```markdown
* Foo
* Bar
* Baz
```

```markdown
*   Foo

    Second paragraph

*   Bar
```

```markdown
1.  Foo

    Second paragraph

1.  Bar
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
