# `MD059` - 連結文字應具描述性

標籤: `accessibility`, `links`

別名: `descriptive-link-text`

參數:

- `prohibited_texts`: 設定值 (`string[]`, 預設值 `["click here","here","link","more"]`)

## 概覽

連結文字應具描述性。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

無。

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
