# `MD031` - 程式碼區塊前後應以空行分隔

標籤: `blank_lines`, `code`

別名: `blanks-around-fences`

參數:

- `list_items`: 設定值 (`boolean`, 預設值 `true`)

## 概覽

程式碼區塊前後應以空行分隔。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

````markdown
Some text
```

```

```

```
Some more text
```

````markdown
Some text

```

```

```

```

Some more text
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
