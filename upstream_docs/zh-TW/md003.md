# `MD003` - 統一標題樣式

標籤: `headings`

別名: `heading-style`

參數:

- `style`: 設定值 (`string`, 預設值 `consistent`)

## 概覽

統一標題樣式。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# ATX style H1

## Closed ATX style H2 ##

Setext style H1
===============
```

```markdown
# ATX style H1

## ATX style H2
```

```markdown
Setext style H1
===============

Setext style H2
---------------

### ATX style H3
```

```markdown
A line of text followed by a horizontal rule becomes a heading
---
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
