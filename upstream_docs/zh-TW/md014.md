# `MD014` - 命令範例前有多餘的美元符號

標籤: `code`

別名: `commands-show-output`

參數:

無。

## 概覽

命令範例前有多餘的美元符號。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
$ ls
$ cat foo
$ less bar
```

```markdown
ls
cat foo
less bar
```

```markdown
$ ls
foo bar
$ cat foo
Hello world
$ cat bar
baz
```

```markdown
$ mkdir test
mkdir: created directory 'test'
$ ls test
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
