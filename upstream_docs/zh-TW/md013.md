# `MD013` - 行長度超過限制

標籤: `line_length`

別名: `line-length`

參數:

- `code_block_line_length`: 設定值 (`integer`, 預設值 `80`)
- `code_blocks`: 設定值 (`boolean`, 預設值 `true`)
- `heading_line_length`: 設定值 (`integer`, 預設值 `80`)
- `headings`: 設定值 (`boolean`, 預設值 `true`)
- `line_length`: 設定值 (`integer`, 預設值 `80`)
- `stern`: 設定值 (`boolean`, 預設值 `false`)
- `strict`: 設定值 (`boolean`, 預設值 `false`)
- `tables`: 設定值 (`boolean`, 預設值 `true`)

## 概覽

行長度超過限制。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
IF THIS LINE IS THE MAXIMUM LENGTH
This line is okay because there are-no-spaces-beyond-that-length
This line is a violation because there are spaces beyond that length
This-line-is-okay-because-there-are-no-spaces-anywhere-within
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
