# `MD001` - 標題層級一次只能增加一級

標籤: `headings`

別名: `heading-increment`

參數:

- `front_matter_title`: 設定值 (`string`, 預設值 `^\s*title\s*[:=]`)

## 概覽

標題層級一次只能增加一級。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# Heading 1

### Heading 3

We skipped out a 2nd level heading in this document
```

```markdown
# Heading 1

## Heading 2

### Heading 3

#### Heading 4

## Another Heading 2

### Another Heading 3
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
