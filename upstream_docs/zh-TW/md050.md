# `MD050` - 統一粗體強調樣式

標籤: `emphasis`

別名: `strong-style`

參數:

- `style`: 設定值 (`string`, 預設值 `consistent`)

## 概覽

統一粗體強調樣式。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
**Text**
__Text__
```

```markdown
**Text**
**Text**
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
