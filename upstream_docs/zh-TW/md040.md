# `MD040` - 圍欄程式碼區塊應指定語言

標籤: `code`, `language`

別名: `fenced-code-language`

參數:

- `allowed_languages`: 設定值 (`string[]`, 預設值 `[]`)
- `language_only`: 設定值 (`boolean`, 預設值 `false`)

## 概覽

圍欄程式碼區塊應指定語言。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
