# `MD022` - 標題前後應以空行分隔

標籤: `blank_lines`, `headings`

別名: `blanks-around-headings`

參數:

- `lines_above`: 設定值 (`integer|integer[]`, 預設值 `1`)
- `lines_below`: 設定值 (`integer|integer[]`, 預設值 `1`)

## 概覽

標題前後應以空行分隔。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# Heading 1
Some text

Some more text
## Heading 2
```

```markdown
# Heading 1

Some text

Some more text

## Heading 2
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
