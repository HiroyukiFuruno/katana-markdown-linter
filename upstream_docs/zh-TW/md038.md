# `MD038` - 程式碼標記內側不要有空格

標籤: `code`, `whitespace`

別名: `no-space-in-code`

參數:

無。

## 概覽

程式碼標記內側不要有空格。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
`some text `

` some text`

`   some text   `
```

```markdown
`some text`
```

```markdown
`` `backticks` ``

`` backtick` ``
```

```markdown
` code `
```

```markdown
` `

`   `
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
