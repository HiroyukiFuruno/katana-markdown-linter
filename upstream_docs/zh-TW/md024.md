# `MD024` - 存在重複標題

標籤: `headings`

別名: `no-duplicate-heading`

參數:

- `siblings_only`: 設定值 (`boolean`, 預設值 `false`)

## 概覽

存在重複標題。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# Some text

## Some text
```

```markdown
# Some text

## Some more text
```

```markdown
# Change log

## 1.0.0

### Features

## 2.0.0

### Features
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
