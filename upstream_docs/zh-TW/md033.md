# `MD033` - 不要使用行內 HTML

標籤: `html`

別名: `no-inline-html`

參數:

- `allowed_elements`: 設定值 (`string[]`, 預設值 `[]`)
- `table_allowed_elements`: 設定值 (`string[]`, 預設值 `[]`)

## 概覽

不要使用行內 HTML。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
<h1>Inline HTML heading</h1>
```

```markdown
# Markdown heading
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
