# `MD052` - 引用連結或圖片缺少定義

標籤: `images`, `links`

別名: `reference-links-images`

參數:

- `ignored_labels`: 設定值 (`string[]`, 預設值 `["x"]`)
- `shortcut_syntax`: 設定值 (`boolean`, 預設值 `false`)

## 概覽

引用連結或圖片缺少定義。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
Full: [text][label]
Collapsed: [label][]
Shortcut: [label]

Full: ![text][image]
Collapsed: ![image][]
Shortcut: ![image]

[label]: https://example.com/label
[image]: https://example.com/image
```

```markdown
- [x] Checked task list item
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
