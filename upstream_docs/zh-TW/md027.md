# `MD027` - 移除引用標記後的多餘空格

標籤: `blockquote`, `indentation`, `whitespace`

別名: `no-multiple-space-blockquote`

參數:

- `list_items`: 設定值 (`boolean`, 預設值 `true`)

## 概覽

移除引用標記後的多餘空格。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
>  This is a blockquote with bad indentation
>  there should only be one.
```

```markdown
> This is a blockquote with correct
> indentation.
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
