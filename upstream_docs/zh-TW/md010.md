# `MD010` - 不要使用硬定位字元

標籤: `hard_tab`, `whitespace`

別名: `no-hard-tabs`

參數:

- `code_blocks`: 設定值 (`boolean`, 預設值 `true`)
- `ignore_code_languages`: 設定值 (`string[]`, 預設值 `[]`)
- `spaces_per_tab`: 設定值 (`integer`, 預設值 `1`)

## 概覽

不要使用硬定位字元。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
Some text

	* hard tab character used to indent the list item
```

```markdown
Some text

    * Spaces used to indent the list item instead
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
