# `MD041` - 文件第一行應為頂層標題

標籤: `headings`

別名: `first-line-h1`, `first-line-heading`

參數:

- `allow_preamble`: 設定值 (`boolean`, 預設值 `false`)
- `front_matter_title`: 設定值 (`string`, 預設值 `^\s*title\s*[:=]`)
- `level`: 設定值 (`integer`, 預設值 `1`)

## 概覽

文件第一行應為頂層標題。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
This is a document without a heading
```

```markdown
# Document Heading

This is a document with a top-level heading
```

```markdown
<h1 align="center"><img src="https://placekitten.com/300/150"/></h1>

This is a document with a top-level HTML heading
```

```markdown
This is a document with preamble text

# Document Heading
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
