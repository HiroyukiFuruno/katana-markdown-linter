# `MD012` - 減少連續空行

標籤: `blank_lines`, `whitespace`

別名: `no-multiple-blanks`

參數:

- `maximum`: 設定值 (`integer`, 預設值 `1`)

## 概覽

減少連續空行。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
Some text here


Some more text here
```

```markdown
Some text here

Some more text here
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
