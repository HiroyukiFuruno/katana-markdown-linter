# `MD032` - 清單前後應以空行分隔

標籤: `blank_lines`, `bullet`, `ol`, `ul`

別名: `blanks-around-lists`

參數:

無。

## 概覽

清單前後應以空行分隔。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
Some text
* List item
* List item

1. List item
2. List item
***
```

```markdown
Some text

* List item
* List item

1. List item
2. List item

***
```

```markdown
1. List item
   More item 1
2. List item
More item 2
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
