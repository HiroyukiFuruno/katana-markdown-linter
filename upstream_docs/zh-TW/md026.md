# `MD026` - 移除標題結尾標點

標籤: `headings`

別名: `no-trailing-punctuation`

參數:

- `punctuation`: 設定值 (`string`, 預設值 `.,;:!。，；：！`)

## 概覽

移除標題結尾標點。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
# This is a heading.
```

```markdown
# This is a heading
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
