# `MD053` - 存在未使用的連結定義

標籤: `images`, `links`

別名: `link-image-reference-definitions`

參數:

- `ignored_definitions`: 設定值 (`string[]`, 預設值 `["//"]`)

## 概覽

存在未使用的連結定義。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
[//]: # (This behaves like a comment)
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
