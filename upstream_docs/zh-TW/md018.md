# `MD018` - ATX 標題的 # 後需要空格

標籤: `atx`, `headings`, `spaces`

別名: `no-missing-space-atx`

參數:

無。

## 概覽

ATX 標題的 # 後需要空格。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
#Heading 1

##Heading 2
```

```markdown
# Heading 1

## Heading 2
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
