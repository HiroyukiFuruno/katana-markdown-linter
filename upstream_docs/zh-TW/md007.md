# `MD007` - 無序清單縮排應符合設定

標籤: `bullet`, `indentation`, `ul`

別名: `ul-indent`

參數:

- `indent`: 設定值 (`integer`, 預設值 `2`)
- `start_indent`: 設定值 (`integer`, 預設值 `2`)
- `start_indented`: 設定值 (`boolean`, 預設值 `false`)

## 概覽

無序清單縮排應符合設定。此規則用來讓 Markdown 文件保持一致、清楚且容易維護。

## 設定

可以使用上方列出的設定鍵調整此規則的行為。

## 範例

```markdown
* List item
   * Nested list item indented by 3 spaces
```

```markdown
* List item
  * Nested list item indented by 2 spaces
```

## 原因

一致的寫法可降低閱讀與維護成本，也能讓自動化工具更可靠地處理文件。
