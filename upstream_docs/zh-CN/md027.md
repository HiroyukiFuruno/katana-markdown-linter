# `MD027` - 删除引用标记后的多余空格

标签: `blockquote`, `indentation`, `whitespace`

别名: `no-multiple-space-blockquote`

参数:

- `list_items`: 配置值 (`boolean`, 默认值 `true`)

## 概览

删除引用标记后的多余空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
>  This is a blockquote with bad indentation
>  there should only be one.
```

```markdown
> This is a blockquote with correct
> indentation.
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
