# `MD052` - 引用链接或图片缺少定义

标签: `images`, `links`

别名: `reference-links-images`

参数:

- `ignored_labels`: 配置值 (`string[]`, 默认值 `["x"]`)
- `shortcut_syntax`: 配置值 (`boolean`, 默认值 `false`)

## 概览

引用链接或图片缺少定义。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Full: [text][label]
Collapsed: [label][]
Shortcut: [label]

Full: ![text][image]
Collapsed: ![image][]
Shortcut: ![image]

[label]: https://example.com/label
[image]: https://example.com/image
```

```markdown
- [x] Checked task list item
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
