# `MD041` - 文件第一行应为顶级标题

标签: `headings`

别名: `first-line-h1`, `first-line-heading`

参数:

- `allow_preamble`: 配置值 (`boolean`, 默认值 `false`)
- `front_matter_title`: 配置值 (`string`, 默认值 `^\s*title\s*[:=]`)
- `level`: 配置值 (`integer`, 默认值 `1`)

## 概览

文件第一行应为顶级标题。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
This is a document without a heading
```

```markdown
# Document Heading

This is a document with a top-level heading
```

```markdown
<h1 align="center"><img src="https://placekitten.com/300/150"/></h1>

This is a document with a top-level HTML heading
```

```markdown
This is a document with preamble text

# Document Heading
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
