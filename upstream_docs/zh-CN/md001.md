# `MD001` - 标题层级一次只能增加一级

标签: `headings`

别名: `heading-increment`

参数:

- `front_matter_title`: 配置值 (`string`, 默认值 `^\s*title\s*[:=]`)

## 概览

标题层级一次只能增加一级。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Heading 1

### Heading 3

We skipped out a 2nd level heading in this document
```

```markdown
# Heading 1

## Heading 2

### Heading 3

#### Heading 4

## Another Heading 2

### Another Heading 3
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
