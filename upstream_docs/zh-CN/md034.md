# `MD034` - 裸 URL 应使用尖括号或链接语法

标签: `links`, `url`

别名: `no-bare-urls`

参数:

无。

## 概览

裸 URL 应使用尖括号或链接语法。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
For more info, visit https://www.example.com/ or email user@example.com.
```

```markdown
For more info, visit <https://www.example.com/> or email <user@example.com>.
```

```markdown
Not a clickable link: `https://www.example.com`
```

```markdown
[https://www.example.com]
```

```markdown
[text [shortcut] text](https://example.com)
```

```markdown
[link \[text\] link](https://example.com)
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
