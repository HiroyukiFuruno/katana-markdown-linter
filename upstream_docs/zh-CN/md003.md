# `MD003` - 统一标题样式

标签: `headings`

别名: `heading-style`

参数:

- `style`: 配置值 (`string`, 默认值 `consistent`)

## 概览

统一标题样式。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# ATX style H1

## Closed ATX style H2 ##

Setext style H1
===============
```

```markdown
# ATX style H1

## ATX style H2
```

```markdown
Setext style H1
===============

Setext style H2
---------------

### ATX style H3
```

```markdown
A line of text followed by a horizontal rule becomes a heading
---
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
