# `MD051` - 链接目标标题片段不存在

标签: `links`

别名: `link-fragments`

参数:

- `ignore_case`: 配置值 (`boolean`, 默认值 `false`)
- `ignored_pattern`: 配置值 (`string`, 默认值 ``)

## 概览

链接目标标题片段不存在。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Heading Name

[Link](#fragment)
```

```markdown
# Heading Name

[Link](#heading-name)
```

```markdown
# Heading Name

[Link](#Heading-Name)
```

```markdown
# Heading Name {#custom-name}

[Link](#custom-name)
```

```markdown
<a id="bookmark"></a>

[Link](#bookmark)
```

```markdown
[Link](#top)
```

```markdown
[Link](#L20)
```

```markdown
[Link](#L19C5-L21C11)
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
