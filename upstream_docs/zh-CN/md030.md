# `MD030` - 列表标记后的空格数量应一致

标签: `ol`, `ul`, `whitespace`

别名: `list-marker-space`

参数:

- `ol_multi`: 配置值 (`integer`, 默认值 `1`)
- `ol_single`: 配置值 (`integer`, 默认值 `1`)
- `ul_multi`: 配置值 (`integer`, 默认值 `1`)
- `ul_single`: 配置值 (`integer`, 默认值 `1`)

## 概览

列表标记后的空格数量应一致。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
* Foo
* Bar
* Baz

1. Foo
1. Bar
1. Baz

1. Foo
   * Bar
1. Baz
```

```markdown
* Foo
* Bar
* Baz
```

```markdown
*   Foo

    Second paragraph

*   Bar
```

```markdown
1.  Foo

    Second paragraph

1.  Bar
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
