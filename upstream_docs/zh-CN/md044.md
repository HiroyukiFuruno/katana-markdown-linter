# `MD044` - 专有名词写法应符合配置

标签: `spelling`

别名: `proper-names`

参数:

- `code_blocks`: 配置值 (`boolean`, 默认值 `true`)
- `html_elements`: 配置值 (`boolean`, 默认值 `true`)
- `names`: 配置值 (`string[]`, 默认值 `[]`)

## 概览

专有名词写法应符合配置。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```json
[
    "JavaScript"
]
```

```json
[
    "GitHub",
    "github.com"
]
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
