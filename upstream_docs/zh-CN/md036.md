# `MD036` - 不要用仅强调的行代替标题

标签: `emphasis`, `headings`

别名: `no-emphasis-as-heading`

参数:

- `punctuation`: 配置值 (`string`, 默认值 `.,;:!?。，；：！？`)

## 概览

不要用仅强调的行代替标题。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
**My document**

Lorem ipsum dolor sit amet...

_Another section_

Consectetur adipiscing elit, sed do eiusmod.
```

```markdown
# My document

Lorem ipsum dolor sit amet...

## Another section

Consectetur adipiscing elit, sed do eiusmod.
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
