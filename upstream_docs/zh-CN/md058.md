# `MD058` - 表格前后应使用空行分隔

标签: `table`

别名: `blanks-around-tables`

参数:

无。

## 概览

表格前后应使用空行分隔。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Some text
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
> Blockquote
```

```markdown
Some text

| Header | Header |
| ------ | ------ |
| Cell   | Cell   |

> Blockquote
```

```markdown
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
This text is part of the table and the next line is blank

Some text
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
