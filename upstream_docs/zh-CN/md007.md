# `MD007` - 无序列表缩进应符合配置

标签: `bullet`, `indentation`, `ul`

别名: `ul-indent`

参数:

- `indent`: 配置值 (`integer`, 默认值 `2`)
- `start_indent`: 配置值 (`integer`, 默认值 `2`)
- `start_indented`: 配置值 (`boolean`, 默认值 `false`)

## 概览

无序列表缩进应符合配置。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
* List item
   * Nested list item indented by 3 spaces
```

```markdown
* List item
  * Nested list item indented by 2 spaces
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
