# `MD047` - 文件末尾应包含换行

标签: `blank_lines`

别名: `single-trailing-newline`

参数:

无。

## 概览

文件末尾应包含换行。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Heading

This file ends without a newline.[EOF]
```

```markdown
# Heading

This file ends with a newline.
[EOF]
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
