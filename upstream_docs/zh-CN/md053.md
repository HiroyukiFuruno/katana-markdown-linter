# `MD053` - 存在未使用的链接定义

标签: `images`, `links`

别名: `link-image-reference-definitions`

参数:

- `ignored_definitions`: 配置值 (`string[]`, 默认值 `["//"]`)

## 概览

存在未使用的链接定义。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
[//]: # (This behaves like a comment)
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
