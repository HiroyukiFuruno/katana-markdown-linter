# `MD024` - 存在重复标题

标签: `headings`

别名: `no-duplicate-heading`

参数:

- `siblings_only`: 配置值 (`boolean`, 默认值 `false`)

## 概览

存在重复标题。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Some text

## Some text
```

```markdown
# Some text

## Some more text
```

```markdown
# Change log

## 1.0.0

### Features

## 2.0.0

### Features
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
