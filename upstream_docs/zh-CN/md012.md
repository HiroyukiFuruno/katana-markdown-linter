# `MD012` - 减少连续的空行

标签: `blank_lines`, `whitespace`

别名: `no-multiple-blanks`

参数:

- `maximum`: 配置值 (`integer`, 默认值 `1`)

## 概览

减少连续的空行。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Some text here


Some more text here
```

```markdown
Some text here

Some more text here
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
