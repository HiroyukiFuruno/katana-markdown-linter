# `MD011` - 修正反向链接语法

标签: `links`

别名: `no-reversed-links`

参数:

无。

## 概览

修正反向链接语法。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
(Incorrect link syntax)[https://www.example.com/]
```

```markdown
[Correct link syntax](https://www.example.com/)
```

```markdown
For (example)[^1]
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
