# `MD031` - 代码块前后应使用空行分隔

标签: `blank_lines`, `code`

别名: `blanks-around-fences`

参数:

- `list_items`: 配置值 (`boolean`, 默认值 `true`)

## 概览

代码块前后应使用空行分隔。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

````markdown
Some text
```

```

```

```
Some more text
```

````markdown
Some text

```

```

```

```

Some more text
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
