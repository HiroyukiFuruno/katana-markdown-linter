# `MD026` - 删除标题末尾的标点

标签: `headings`

别名: `no-trailing-punctuation`

参数:

- `punctuation`: 配置值 (`string`, 默认值 `.,;:!。，；：！`)

## 概览

删除标题末尾的标点。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# This is a heading.
```

```markdown
# This is a heading
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
