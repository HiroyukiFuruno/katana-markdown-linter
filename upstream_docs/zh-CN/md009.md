# `MD009` - 删除行尾多余空格

标签: `whitespace`

别名: `no-trailing-spaces`

参数:

- `br_spaces`: 配置值 (`integer`, 默认值 `2`)
- `code_blocks`: 配置值 (`boolean`, 默认值 `false`)
- `list_item_empty_lines`: 配置值 (`boolean`, 默认值 `false`)
- `strict`: 配置值 (`boolean`, 默认值 `false`)

## 概览

删除行尾多余空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Text text text
text[2 spaces]
```

```markdown
- list item text
  [2 spaces]
  list item text
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
