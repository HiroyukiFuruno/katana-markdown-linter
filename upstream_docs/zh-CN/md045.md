# `MD045` - 图片应提供替代文本

标签: `accessibility`, `images`

别名: `no-alt-text`

参数:

无。

## 概览

图片应提供替代文本。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
![Alternate text](image.jpg)
```

```markdown
![Alternate text][ref]

...

[ref]: image.jpg "Optional title"
```

```html
<img src="image.jpg" alt="Alternate text" />
```

```html
<img src="image.jpg" aria-hidden="true" />
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
