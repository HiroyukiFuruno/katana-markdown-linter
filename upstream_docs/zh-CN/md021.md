# `MD021` - 闭合 ATX 标题内部只能有一个空格

标签: `atx_closed`, `headings`, `spaces`

别名: `no-multiple-space-closed-atx`

参数:

无。

## 概览

闭合 ATX 标题内部只能有一个空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
#  Heading 1  #

##  Heading 2  ##
```

```markdown
# Heading 1 #

## Heading 2 ##
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
