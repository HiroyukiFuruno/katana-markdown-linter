# `MD022` - 标题前后应使用空行分隔

标签: `blank_lines`, `headings`

别名: `blanks-around-headings`

参数:

- `lines_above`: 配置值 (`integer|integer[]`, 默认值 `1`)
- `lines_below`: 配置值 (`integer|integer[]`, 默认值 `1`)

## 概览

标题前后应使用空行分隔。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Heading 1
Some text

Some more text
## Heading 2
```

```markdown
# Heading 1

Some text

Some more text

## Heading 2
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
