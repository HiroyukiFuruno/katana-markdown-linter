# `MD004` - 统一无序列表标记样式

标签: `bullet`, `ul`

别名: `ul-style`

参数:

- `style`: 配置值 (`string`, 默认值 `consistent`)

## 概览

统一无序列表标记样式。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
* Item 1
+ Item 2
- Item 3
```

```markdown
* Item 1
* Item 2
* Item 3
```

```markdown
* Item 1
  + Item 2
    - Item 3
  + Item 4
* Item 4
  + Item 5
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
