# `MD013` - 行长度超过限制

标签: `line_length`

别名: `line-length`

参数:

- `code_block_line_length`: 配置值 (`integer`, 默认值 `80`)
- `code_blocks`: 配置值 (`boolean`, 默认值 `true`)
- `heading_line_length`: 配置值 (`integer`, 默认值 `80`)
- `headings`: 配置值 (`boolean`, 默认值 `true`)
- `line_length`: 配置值 (`integer`, 默认值 `80`)
- `stern`: 配置值 (`boolean`, 默认值 `false`)
- `strict`: 配置值 (`boolean`, 默认值 `false`)
- `tables`: 配置值 (`boolean`, 默认值 `true`)

## 概览

行长度超过限制。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
IF THIS LINE IS THE MAXIMUM LENGTH
This line is okay because there are-no-spaces-beyond-that-length
This line is a violation because there are spaces beyond that length
This-line-is-okay-because-there-are-no-spaces-anywhere-within
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
