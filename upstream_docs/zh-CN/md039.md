# `MD039` - 链接文本内部不要有多余空格

标签: `links`, `whitespace`

别名: `no-space-in-links`

参数:

无。

## 概览

链接文本内部不要有多余空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
[ a link ](https://www.example.com/)
```

```markdown
[a link](https://www.example.com/)
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
