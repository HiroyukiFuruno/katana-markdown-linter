# `MD043` - 标题结构应符合要求

标签: `headings`

别名: `required-headings`

参数:

- `headings`: 配置值 (`string[]`, 默认值 `[]`)
- `match_case`: 配置值 (`boolean`, 默认值 `false`)

## 概览

标题结构应符合要求。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Heading
## Item
### Detail
```

```json
[
    "# Heading",
    "## Item",
    "### Detail"
]
```

```markdown
# Heading
## Item
### Detail (optional)
## Foot
### Notes (optional)
```

```json
[
    "# Heading",
    "## Item",
    "*",
    "## Foot",
    "*"
]
```

```markdown
# Project Name
## Description
## Examples
```

```json
[
    "?",
    "## Description",
    "## Examples"
]
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
