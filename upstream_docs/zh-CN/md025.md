# `MD025` - 同一文档中只能有一个顶级标题

标签: `headings`

别名: `single-h1`, `single-title`

参数:

- `front_matter_title`: 配置值 (`string`, 默认值 `^\s*title\s*[:=]`)
- `level`: 配置值 (`integer`, 默认值 `1`)

## 概览

同一文档中只能有一个顶级标题。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
# Top level heading

# Another top-level heading
```

```markdown
# Title

## Heading

## Another heading
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
