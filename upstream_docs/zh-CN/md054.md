# `MD054` - 链接和图片样式应符合配置

标签: `images`, `links`

别名: `link-image-style`

参数:

- `autolink`: 配置值 (`boolean`, 默认值 `true`)
- `collapsed`: 配置值 (`boolean`, 默认值 `true`)
- `full`: 配置值 (`boolean`, 默认值 `true`)
- `inline`: 配置值 (`boolean`, 默认值 `true`)
- `shortcut`: 配置值 (`boolean`, 默认值 `true`)
- `url_inline`: 配置值 (`boolean`, 默认值 `true`)

## 概览

链接和图片样式应符合配置。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
<https://example.com>
```

```markdown
[link](https://example.com)

![image](https://example.com)
```

```markdown
[link][url]

![image][url]

[url]: https://example.com
```

```markdown
[url][]

![url][]

[url]: https://example.com
```

```markdown
[url]

![url]

[url]: https://example.com
```

```markdown
[https://example.com](https://example.com)
```

```markdown
<https://example.com>
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
