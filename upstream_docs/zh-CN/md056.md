# `MD056` - 表格列数应保持一致

标签: `table`

别名: `table-column-count`

参数:

无。

## 概览

表格列数应保持一致。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
| Cell   |
| Cell   | Cell   | Cell   |
```

```markdown
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
| Cell   | Cell   |
| Cell   | Cell   |
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
