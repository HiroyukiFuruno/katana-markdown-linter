# `MD042` - 不要使用空链接

标签: `links`

别名: `no-empty-links`

参数:

无。

## 概览

不要使用空链接。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
[an empty link]()
```

```markdown
[a valid link](https://example.com/)
```

```markdown
[an empty fragment](#)
```

```markdown
[a valid fragment](#fragment)
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
