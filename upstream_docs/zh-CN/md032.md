# `MD032` - 列表前后应使用空行分隔

标签: `blank_lines`, `bullet`, `ol`, `ul`

别名: `blanks-around-lists`

参数:

无。

## 概览

列表前后应使用空行分隔。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Some text
* List item
* List item

1. List item
2. List item
***
```

```markdown
Some text

* List item
* List item

1. List item
2. List item

***
```

```markdown
1. List item
   More item 1
2. List item
More item 2
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
