# `MD033` - 不要使用内联 HTML

标签: `html`

别名: `no-inline-html`

参数:

- `allowed_elements`: 配置值 (`string[]`, 默认值 `[]`)
- `table_allowed_elements`: 配置值 (`string[]`, 默认值 `[]`)

## 概览

不要使用内联 HTML。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
<h1>Inline HTML heading</h1>
```

```markdown
# Markdown heading
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
