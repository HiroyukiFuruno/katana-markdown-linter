# `MD023` - 标题应从行首开始

标签: `headings`, `spaces`

别名: `heading-start-left`

参数:

无。

## 概览

标题应从行首开始。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Some text

  # Indented heading
```

```markdown
Some text

# Heading
```

```markdown
> # Heading in Block Quote
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
