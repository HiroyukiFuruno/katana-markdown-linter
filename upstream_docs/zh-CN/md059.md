# `MD059` - 链接文本应具有描述性

标签: `accessibility`, `links`

别名: `descriptive-link-text`

参数:

- `prohibited_texts`: 配置值 (`string[]`, 默认值 `["click here","here","link","more"]`)

## 概览

链接文本应具有描述性。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

无。

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
