# `MD005` - 同级列表项的缩进应保持一致

标签: `bullet`, `indentation`, `ul`

别名: `list-indent`

参数:

无。

## 概览

同级列表项的缩进应保持一致。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
* Item 1
  * Nested Item 1
  * Nested Item 2
   * A misaligned item
```

```markdown
* Item 1
  * Nested Item 1
  * Nested Item 2
  * Nested Item 3
```

```markdown
...
8. Item
9. Item
10. Item
11. Item
...
```

```markdown
...
 8. Item
 9. Item
10. Item
11. Item
...
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
