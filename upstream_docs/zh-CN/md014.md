# `MD014` - 命令示例前存在多余的美元符号

标签: `code`

别名: `commands-show-output`

参数:

无。

## 概览

命令示例前存在多余的美元符号。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
$ ls
$ cat foo
$ less bar
```

```markdown
ls
cat foo
less bar
```

```markdown
$ ls
foo bar
$ cat foo
Hello world
$ cat bar
baz
```

```markdown
$ mkdir test
mkdir: created directory 'test'
$ ls test
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
