# `MD010` - 不要使用硬制表符

标签: `hard_tab`, `whitespace`

别名: `no-hard-tabs`

参数:

- `code_blocks`: 配置值 (`boolean`, 默认值 `true`)
- `ignore_code_languages`: 配置值 (`string[]`, 默认值 `[]`)
- `spaces_per_tab`: 配置值 (`integer`, 默认值 `1`)

## 概览

不要使用硬制表符。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
Some text

	* hard tab character used to indent the list item
```

```markdown
Some text

    * Spaces used to indent the list item instead
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
