# `MD018` - ATX 标题的 # 后需要空格

标签: `atx`, `headings`, `spaces`

别名: `no-missing-space-atx`

参数:

无。

## 概览

ATX 标题的 # 后需要空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
#Heading 1

##Heading 2
```

```markdown
# Heading 1

## Heading 2
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
