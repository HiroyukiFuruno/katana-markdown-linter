# `MD048` - 统一围栏代码块标记样式

标签: `code`

别名: `code-fence-style`

参数:

- `style`: 配置值 (`string`, 默认值 `consistent`)

## 概览

统一围栏代码块标记样式。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
