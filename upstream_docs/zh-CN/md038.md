# `MD038` - 代码标记内部不要有空格

标签: `code`, `whitespace`

别名: `no-space-in-code`

参数:

无。

## 概览

代码标记内部不要有空格。此规则用于让 Markdown 文档保持一致、清晰且便于维护。

## 配置

可以使用上方列出的配置键调整此规则的行为。

## 示例

```markdown
`some text `

` some text`

`   some text   `
```

```markdown
`some text`
```

```markdown
`` `backticks` ``

`` backtick` ``
```

```markdown
` code `
```

```markdown
` `

`   `
```

## 原因

一致的写法能降低阅读和维护成本，也能让自动化工具更可靠地处理文档。
