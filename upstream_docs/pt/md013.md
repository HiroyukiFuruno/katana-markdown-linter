# `MD013` - O comprimento da linha excede o limite

Tags: `line_length`

Aliases: `line-length`

Parâmetros:

- `code_block_line_length`: valor de configuração (`integer`, padrão `80`)
- `code_blocks`: valor de configuração (`boolean`, padrão `true`)
- `heading_line_length`: valor de configuração (`integer`, padrão `80`)
- `headings`: valor de configuração (`boolean`, padrão `true`)
- `line_length`: valor de configuração (`integer`, padrão `80`)
- `stern`: valor de configuração (`boolean`, padrão `false`)
- `strict`: valor de configuração (`boolean`, padrão `false`)
- `tables`: valor de configuração (`boolean`, padrão `true`)

## Visão geral

O comprimento da linha excede o limite. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
IF THIS LINE IS THE MAXIMUM LENGTH
This line is okay because there are-no-spaces-beyond-that-length
This line is a violation because there are spaces beyond that length
This-line-is-okay-because-there-are-no-spaces-anywhere-within
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
