# `MD022` - Títulos devem ser separados por linhas em branco

Tags: `blank_lines`, `headings`

Aliases: `blanks-around-headings`

Parâmetros:

- `lines_above`: valor de configuração (`integer|integer[]`, padrão `1`)
- `lines_below`: valor de configuração (`integer|integer[]`, padrão `1`)

## Visão geral

Títulos devem ser separados por linhas em branco. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# Heading 1
Some text

Some more text
## Heading 2
```

```markdown
# Heading 1

Some text

Some more text

## Heading 2
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
