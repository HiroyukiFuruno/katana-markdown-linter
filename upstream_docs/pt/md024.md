# `MD024` - Há títulos duplicados

Tags: `headings`

Aliases: `no-duplicate-heading`

Parâmetros:

- `siblings_only`: valor de configuração (`boolean`, padrão `false`)

## Visão geral

Há títulos duplicados. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# Some text

## Some text
```

```markdown
# Some text

## Some more text
```

```markdown
# Change log

## 1.0.0

### Features

## 2.0.0

### Features
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
