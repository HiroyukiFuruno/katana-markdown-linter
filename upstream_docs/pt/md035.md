# `MD035` - Mantenha um estilo consistente para linhas horizontais

Tags: `hr`

Aliases: `hr-style`

Parâmetros:

- `style`: valor de configuração (`string`, padrão `consistent`)

## Visão geral

Mantenha um estilo consistente para linhas horizontais. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
---

- - -

***

* * *

****
```

```markdown
---

---
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
