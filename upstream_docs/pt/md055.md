# `MD055` - Mantenha um estilo consistente para a linha divisória da tabela

Tags: `table`

Aliases: `table-pipe-style`

Parâmetros:

- `style`: valor de configuração (`string`, padrão `consistent`)

## Visão geral

Mantenha um estilo consistente para a linha divisória da tabela. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
| Header | Header |
| ------ | ------
  Cell   | Cell   |
```

```markdown
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
```

```markdown
| Header | Header |
| ------ | ------ |
| Cell   | Cell   |
This text is part of the table
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
