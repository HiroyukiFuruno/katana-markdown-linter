# `MD040` - Blocos de código cercados devem indicar a linguagem

Tags: `code`, `language`

Aliases: `fenced-code-language`

Parâmetros:

- `allowed_languages`: valor de configuração (`string[]`, padrão `[]`)
- `language_only`: valor de configuração (`boolean`, padrão `false`)

## Visão geral

Blocos de código cercados devem indicar a linguagem. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.
