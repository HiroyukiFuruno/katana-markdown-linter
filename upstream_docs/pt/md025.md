# `MD025` - Use apenas um título de nível superior por documento

Tags: `headings`

Aliases: `single-h1`, `single-title`

Parâmetros:

- `front_matter_title`: valor de configuração (`string`, padrão `^\s*title\s*[:=]`)
- `level`: valor de configuração (`integer`, padrão `1`)

## Visão geral

Use apenas um título de nível superior por documento. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# Top level heading

# Another top-level heading
```

```markdown
# Title

## Heading

## Another heading
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
