# `MD048` - Mantenha um estilo consistente para cercas de código

Tags: `code`

Aliases: `code-fence-style`

Parâmetros:

- `style`: valor de configuração (`string`, padrão `consistent`)

## Visão geral

Mantenha um estilo consistente para cercas de código. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.
