# `MD051` - O fragmento de título apontado pelo link não existe

Tags: `links`

Aliases: `link-fragments`

Parâmetros:

- `ignore_case`: valor de configuração (`boolean`, padrão `false`)
- `ignored_pattern`: valor de configuração (`string`, padrão ``)

## Visão geral

O fragmento de título apontado pelo link não existe. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# Heading Name

[Link](#fragment)
```

```markdown
# Heading Name

[Link](#heading-name)
```

```markdown
# Heading Name

[Link](#Heading-Name)
```

```markdown
# Heading Name {#custom-name}

[Link](#custom-name)
```

```markdown
<a id="bookmark"></a>

[Link](#bookmark)
```

```markdown
[Link](#top)
```

```markdown
[Link](#L20)
```

```markdown
[Link](#L19C5-L21C11)
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
