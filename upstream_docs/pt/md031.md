# `MD031` - Blocos de código devem ser separados por linhas em branco

Tags: `blank_lines`, `code`

Aliases: `blanks-around-fences`

Parâmetros:

- `list_items`: valor de configuração (`boolean`, padrão `true`)

## Visão geral

Blocos de código devem ser separados por linhas em branco. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
