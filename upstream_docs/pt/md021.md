# `MD021` - Títulos ATX fechados devem ter apenas um espaço interno

Tags: `atx_closed`, `headings`, `spaces`

Aliases: `no-multiple-space-closed-atx`

Parâmetros:

Nenhum.

## Visão geral

Títulos ATX fechados devem ter apenas um espaço interno. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
#  Heading 1  #

##  Heading 2  ##
```

```markdown
# Heading 1 #

## Heading 2 ##
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
