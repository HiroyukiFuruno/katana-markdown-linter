# `MD060` - Alinhe os espaços nas células da tabela

Tags: `table`

Aliases: `table-column-style`

Parâmetros:

- `aligned_delimiter`: valor de configuração (`boolean`, padrão `false`)
- `style`: valor de configuração (`string`, padrão `any`)

## Visão geral

Alinhe os espaços nas células da tabela. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
| Character | Meaning |
| --------- | ------- |
| Y         | Yes     |
| N         | No      |
```

```markdown
| Character | Meaning |
|-----------|---------|
|     Y     |     Yes |
|     N     |      No |
```

```markdown
| Character | Meaning |
| --- | --- |
| Y | Yes |
| N | No |
```

```markdown
|Character|Meaning|
|---|---|
|Y|Yes|
|N|No|
```

```markdown
| Character | Meaning |
| --------- | ------- |
| Y | Yes |
| N | No |
```

```markdown
|Character|Meaning|
|---------|-------|
|Y|Yes|
|N|No|
```

```markdown
Character | Meaning
--- | ---
Y | Yes
N | No
```

```markdown
| Response | Emoji |
| -------- | ----- |
| Yes      | ✅    |
| No       | ❎    |
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
