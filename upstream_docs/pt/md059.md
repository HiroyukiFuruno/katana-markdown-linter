# `MD059` - O texto do link deve ser descritivo

Tags: `accessibility`, `links`

Aliases: `descriptive-link-text`

Parâmetros:

- `prohibited_texts`: valor de configuração (`string[]`, padrão `["click here","here","link","more"]`)

## Visão geral

O texto do link deve ser descritivo. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

Nenhum.

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
