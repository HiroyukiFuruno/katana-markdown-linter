# `MD050` - Mantenha um estilo consistente de ênfase forte

Tags: `emphasis`

Aliases: `strong-style`

Parâmetros:

- `style`: valor de configuração (`string`, padrão `consistent`)

## Visão geral

Mantenha um estilo consistente de ênfase forte. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
**Text**
__Text__
```

```markdown
**Text**
**Text**
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
