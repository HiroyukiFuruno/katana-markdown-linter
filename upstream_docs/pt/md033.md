# `MD033` - Não use HTML inline

Tags: `html`

Aliases: `no-inline-html`

Parâmetros:

- `allowed_elements`: valor de configuração (`string[]`, padrão `[]`)
- `table_allowed_elements`: valor de configuração (`string[]`, padrão `[]`)

## Visão geral

Não use HTML inline. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
<h1>Inline HTML heading</h1>
```

```markdown
# Markdown heading
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
