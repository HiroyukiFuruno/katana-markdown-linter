# `MD009` - Remova espaços extras no fim da linha

Tags: `whitespace`

Aliases: `no-trailing-spaces`

Parâmetros:

- `br_spaces`: valor de configuração (`integer`, padrão `2`)
- `code_blocks`: valor de configuração (`boolean`, padrão `false`)
- `list_item_empty_lines`: valor de configuração (`boolean`, padrão `false`)
- `strict`: valor de configuração (`boolean`, padrão `false`)

## Visão geral

Remova espaços extras no fim da linha. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
Text text text
text[2 spaces]
```

```markdown
- list item text
  [2 spaces]
  list item text
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
