# `MD052` - Falta a definição do link ou da imagem de referência

Tags: `images`, `links`

Aliases: `reference-links-images`

Parâmetros:

- `ignored_labels`: valor de configuração (`string[]`, padrão `["x"]`)
- `shortcut_syntax`: valor de configuração (`boolean`, padrão `false`)

## Visão geral

Falta a definição do link ou da imagem de referência. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
Full: [text][label]
Collapsed: [label][]
Shortcut: [label]

Full: ![text][image]
Collapsed: ![image][]
Shortcut: ![image]

[label]: https://example.com/label
[image]: https://example.com/image
```

```markdown
- [x] Checked task list item
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
