# `MD014` - Há um cifrão desnecessário antes do exemplo de comando

Tags: `code`

Aliases: `commands-show-output`

Parâmetros:

Nenhum.

## Visão geral

Há um cifrão desnecessário antes do exemplo de comando. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
$ ls
$ cat foo
$ less bar
```

```markdown
ls
cat foo
less bar
```

```markdown
$ ls
foo bar
$ cat foo
Hello world
$ cat bar
baz
```

```markdown
$ mkdir test
mkdir: created directory 'test'
$ ls test
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
