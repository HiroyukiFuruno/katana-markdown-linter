# `MD004` - Mantenha um estilo consistente para listas não ordenadas

Tags: `bullet`, `ul`

Aliases: `ul-style`

Parâmetros:

- `style`: valor de configuração (`string`, padrão `consistent`)

## Visão geral

Mantenha um estilo consistente para listas não ordenadas. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
* Item 1
+ Item 2
- Item 3
```

```markdown
* Item 1
* Item 2
* Item 3
```

```markdown
* Item 1
  + Item 2
    - Item 3
  + Item 4
* Item 4
  + Item 5
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
