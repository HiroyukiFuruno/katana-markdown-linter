# `MD030` - Mantenha o mesmo número de espaços após marcadores de lista

Tags: `ol`, `ul`, `whitespace`

Aliases: `list-marker-space`

Parâmetros:

- `ol_multi`: valor de configuração (`integer`, padrão `1`)
- `ol_single`: valor de configuração (`integer`, padrão `1`)
- `ul_multi`: valor de configuração (`integer`, padrão `1`)
- `ul_single`: valor de configuração (`integer`, padrão `1`)

## Visão geral

Mantenha o mesmo número de espaços após marcadores de lista. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
* Foo
* Bar
* Baz

1. Foo
1. Bar
1. Baz

1. Foo
   * Bar
1. Baz
```

```markdown
* Foo
* Bar
* Baz
```

```markdown
*   Foo

    Second paragraph

*   Bar
```

```markdown
1.  Foo

    Second paragraph

1.  Bar
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
