# `MD044` - Ajuste nomes próprios à grafia configurada

Tags: `spelling`

Aliases: `proper-names`

Parâmetros:

- `code_blocks`: valor de configuração (`boolean`, padrão `true`)
- `html_elements`: valor de configuração (`boolean`, padrão `true`)
- `names`: valor de configuração (`string[]`, padrão `[]`)

## Visão geral

Ajuste nomes próprios à grafia configurada. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```json
[
    "JavaScript"
]
```

```json
[
    "GitHub",
    "github.com"
]
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
