# `MD039` - Remova espaços extras dentro do texto do link

Tags: `links`, `whitespace`

Aliases: `no-space-in-links`

Parâmetros:

Nenhum.

## Visão geral

Remova espaços extras dentro do texto do link. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
[ a link ](https://www.example.com/)
```

```markdown
[a link](https://www.example.com/)
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
