# `MD032` - Listas devem ser separadas por linhas em branco

Tags: `blank_lines`, `bullet`, `ol`, `ul`

Aliases: `blanks-around-lists`

Parâmetros:

Nenhum.

## Visão geral

Listas devem ser separadas por linhas em branco. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
Some text
* List item
* List item

1. List item
2. List item
***
```

```markdown
Some text

* List item
* List item

1. List item
2. List item

***
```

```markdown
1. List item
   More item 1
2. List item
More item 2
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
