# `MD047` - Arquivos devem terminar com uma quebra de linha

Tags: `blank_lines`

Aliases: `single-trailing-newline`

Parâmetros:

Nenhum.

## Visão geral

Arquivos devem terminar com uma quebra de linha. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# Heading

This file ends without a newline.[EOF]
```

```markdown
# Heading

This file ends with a newline.
[EOF]
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
