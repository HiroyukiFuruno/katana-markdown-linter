# `MD026` - Remova a pontuação no fim do título

Tags: `headings`

Aliases: `no-trailing-punctuation`

Parâmetros:

- `punctuation`: valor de configuração (`string`, padrão `.,;:!。，；：！`)

## Visão geral

Remova a pontuação no fim do título. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
# This is a heading.
```

```markdown
# This is a heading
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
