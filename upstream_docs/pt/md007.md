# `MD007` - Ajuste a indentação das listas não ordenadas à configuração

Tags: `bullet`, `indentation`, `ul`

Aliases: `ul-indent`

Parâmetros:

- `indent`: valor de configuração (`integer`, padrão `2`)
- `start_indent`: valor de configuração (`integer`, padrão `2`)
- `start_indented`: valor de configuração (`boolean`, padrão `false`)

## Visão geral

Ajuste a indentação das listas não ordenadas à configuração. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
* List item
   * Nested list item indented by 3 spaces
```

```markdown
* List item
  * Nested list item indented by 2 spaces
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
