# `MD036` - Não use uma linha apenas enfatizada como título

Tags: `emphasis`, `headings`

Aliases: `no-emphasis-as-heading`

Parâmetros:

- `punctuation`: valor de configuração (`string`, padrão `.,;:!?。，；：！？`)

## Visão geral

Não use uma linha apenas enfatizada como título. Esta regra ajuda a manter documentos Markdown consistentes, legíveis e fáceis de manter.

## Configuração

Use as chaves de configuração listadas acima para ajustar o comportamento desta regra.

## Exemplos

```markdown
**My document**

Lorem ipsum dolor sit amet...

_Another section_

Consectetur adipiscing elit, sed do eiusmod.
```

```markdown
# My document

Lorem ipsum dolor sit amet...

## Another section

Consectetur adipiscing elit, sed do eiusmod.
```

## Motivo

Uma escrita consistente reduz o custo de leitura e manutenção e torna a automação mais confiável.
