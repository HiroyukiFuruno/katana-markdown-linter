# `MD049` - Conservez un style d'emphase cohérent

Étiquettes: `emphasis`

Alias: `emphasis-style`

Paramètres:

- `style`: valeur de configuration (`string`, défaut `consistent`)

## Vue d'ensemble

Conservez un style d'emphase cohérent. Cette règle aide à garder les documents Markdown cohérents, lisibles et faciles à maintenir.

## Configuration

Utilisez les clés de configuration ci-dessus pour ajuster le comportement de cette règle.

## Exemples

```markdown
*Text*
_Text_
```

```markdown
*Text*
*Text*
```

## Raison

Une écriture cohérente réduit le coût de lecture et de maintenance et rend l'automatisation plus fiable.
