# `MD012` - 연속된 빈 줄을 줄이세요

태그: `blank_lines`, `whitespace`

별칭: `no-multiple-blanks`

매개변수:

- `maximum`: 설정값 (`integer`, 기본값 `1`)

## 개요

연속된 빈 줄을 줄이세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
Some text here


Some more text here
```

```markdown
Some text here

Some more text here
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
