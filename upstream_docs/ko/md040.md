# `MD040` - 펜스 코드 블록에는 언어를 지정하세요

태그: `code`, `language`

별칭: `fenced-code-language`

매개변수:

- `allowed_languages`: 설정값 (`string[]`, 기본값 `[]`)
- `language_only`: 설정값 (`boolean`, 기본값 `false`)

## 개요

펜스 코드 블록에는 언어를 지정하세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
