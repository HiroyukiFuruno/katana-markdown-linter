# `MD013` - 줄 길이가 제한을 초과했습니다

태그: `line_length`

별칭: `line-length`

매개변수:

- `code_block_line_length`: 설정값 (`integer`, 기본값 `80`)
- `code_blocks`: 설정값 (`boolean`, 기본값 `true`)
- `heading_line_length`: 설정값 (`integer`, 기본값 `80`)
- `headings`: 설정값 (`boolean`, 기본값 `true`)
- `line_length`: 설정값 (`integer`, 기본값 `80`)
- `stern`: 설정값 (`boolean`, 기본값 `false`)
- `strict`: 설정값 (`boolean`, 기본값 `false`)
- `tables`: 설정값 (`boolean`, 기본값 `true`)

## 개요

줄 길이가 제한을 초과했습니다. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
IF THIS LINE IS THE MAXIMUM LENGTH
This line is okay because there are-no-spaces-beyond-that-length
This line is a violation because there are spaces beyond that length
This-line-is-okay-because-there-are-no-spaces-anywhere-within
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
