# `MD031` - 코드 블록 앞뒤에는 빈 줄을 두세요

태그: `blank_lines`, `code`

별칭: `blanks-around-fences`

매개변수:

- `list_items`: 설정값 (`boolean`, 기본값 `true`)

## 개요

코드 블록 앞뒤에는 빈 줄을 두세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

````markdown
Some text
```

```

```

```
Some more text
```

````markdown
Some text

```

```

```

```

Some more text
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
