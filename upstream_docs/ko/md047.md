# `MD047` - 파일 끝에는 줄바꿈을 넣으세요

태그: `blank_lines`

별칭: `single-trailing-newline`

매개변수:

없음.

## 개요

파일 끝에는 줄바꿈을 넣으세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
# Heading

This file ends without a newline.[EOF]
```

```markdown
# Heading

This file ends with a newline.
[EOF]
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
