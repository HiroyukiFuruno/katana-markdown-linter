# `MD026` - 제목 끝의 문장 부호를 제거하세요

태그: `headings`

별칭: `no-trailing-punctuation`

매개변수:

- `punctuation`: 설정값 (`string`, 기본값 `.,;:!。，；：！`)

## 개요

제목 끝의 문장 부호를 제거하세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
# This is a heading.
```

```markdown
# This is a heading
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
