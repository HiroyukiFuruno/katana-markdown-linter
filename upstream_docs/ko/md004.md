# `MD004` - 순서 없는 목록의 표시 스타일을 통일하세요

태그: `bullet`, `ul`

별칭: `ul-style`

매개변수:

- `style`: 설정값 (`string`, 기본값 `consistent`)

## 개요

순서 없는 목록의 표시 스타일을 통일하세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
* Item 1
+ Item 2
- Item 3
```

```markdown
* Item 1
* Item 2
* Item 3
```

```markdown
* Item 1
  + Item 2
    - Item 3
  + Item 4
* Item 4
  + Item 5
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
