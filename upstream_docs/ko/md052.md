# `MD052` - 참조 링크나 이미지의 정의가 없습니다

태그: `images`, `links`

별칭: `reference-links-images`

매개변수:

- `ignored_labels`: 설정값 (`string[]`, 기본값 `["x"]`)
- `shortcut_syntax`: 설정값 (`boolean`, 기본값 `false`)

## 개요

참조 링크나 이미지의 정의가 없습니다. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
Full: [text][label]
Collapsed: [label][]
Shortcut: [label]

Full: ![text][image]
Collapsed: ![image][]
Shortcut: ![image]

[label]: https://example.com/label
[image]: https://example.com/image
```

```markdown
- [x] Checked task list item
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
