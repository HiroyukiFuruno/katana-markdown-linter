# `MD044` - 고유명사 표기를 설정에 맞추세요

태그: `spelling`

별칭: `proper-names`

매개변수:

- `code_blocks`: 설정값 (`boolean`, 기본값 `true`)
- `html_elements`: 설정값 (`boolean`, 기본값 `true`)
- `names`: 설정값 (`string[]`, 기본값 `[]`)

## 개요

고유명사 표기를 설정에 맞추세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```json
[
    "JavaScript"
]
```

```json
[
    "GitHub",
    "github.com"
]
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
