# `MD029` - 순서 있는 목록 번호를 올바르게 정렬하세요

태그: `ol`

별칭: `ol-prefix`

매개변수:

- `style`: 설정값 (`string`, 기본값 `one_or_ordered`)

## 개요

순서 있는 목록 번호를 올바르게 정렬하세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
1. Do this.
1. Do that.
1. Done.
```

```markdown
1. Do this.
2. Do that.
3. Done.
```

```markdown
0. Do this.
1. Do that.
2. Done.
```

```markdown
0. Do this.
0. Do that.
0. Done.
```

```markdown
1. Do this.
3. Done.
```

```markdown
...
08. Item
09. Item
10. Item
11. Item
...
```

```text
Code block
```

```text
   Code block
   ```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
