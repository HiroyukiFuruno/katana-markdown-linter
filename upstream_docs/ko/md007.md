# `MD007` - 순서 없는 목록 들여쓰기를 설정에 맞추세요

태그: `bullet`, `indentation`, `ul`

별칭: `ul-indent`

매개변수:

- `indent`: 설정값 (`integer`, 기본값 `2`)
- `start_indent`: 설정값 (`integer`, 기본값 `2`)
- `start_indented`: 설정값 (`boolean`, 기본값 `false`)

## 개요

순서 없는 목록 들여쓰기를 설정에 맞추세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
* List item
   * Nested list item indented by 3 spaces
```

```markdown
* List item
  * Nested list item indented by 2 spaces
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
