# `MD024` - 중복된 제목이 있습니다

태그: `headings`

별칭: `no-duplicate-heading`

매개변수:

- `siblings_only`: 설정값 (`boolean`, 기본값 `false`)

## 개요

중복된 제목이 있습니다. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
# Some text

## Some text
```

```markdown
# Some text

## Some more text
```

```markdown
# Change log

## 1.0.0

### Features

## 2.0.0

### Features
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
