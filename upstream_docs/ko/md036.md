# `MD036` - 강조만 있는 줄을 제목 대신 사용하지 마세요

태그: `emphasis`, `headings`

별칭: `no-emphasis-as-heading`

매개변수:

- `punctuation`: 설정값 (`string`, 기본값 `.,;:!?。，；：！？`)

## 개요

강조만 있는 줄을 제목 대신 사용하지 마세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
**My document**

Lorem ipsum dolor sit amet...

_Another section_

Consectetur adipiscing elit, sed do eiusmod.
```

```markdown
# My document

Lorem ipsum dolor sit amet...

## Another section

Consectetur adipiscing elit, sed do eiusmod.
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
