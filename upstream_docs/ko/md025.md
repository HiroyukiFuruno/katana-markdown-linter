# `MD025` - 문서에는 최상위 제목을 하나만 두세요

태그: `headings`

별칭: `single-h1`, `single-title`

매개변수:

- `front_matter_title`: 설정값 (`string`, 기본값 `^\s*title\s*[:=]`)
- `level`: 설정값 (`integer`, 기본값 `1`)

## 개요

문서에는 최상위 제목을 하나만 두세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
# Top level heading

# Another top-level heading
```

```markdown
# Title

## Heading

## Another heading
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
