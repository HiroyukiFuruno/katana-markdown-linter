# `MD030` - 목록 표시 뒤의 공백 수를 맞추세요

태그: `ol`, `ul`, `whitespace`

별칭: `list-marker-space`

매개변수:

- `ol_multi`: 설정값 (`integer`, 기본값 `1`)
- `ol_single`: 설정값 (`integer`, 기본값 `1`)
- `ul_multi`: 설정값 (`integer`, 기본값 `1`)
- `ul_single`: 설정값 (`integer`, 기본값 `1`)

## 개요

목록 표시 뒤의 공백 수를 맞추세요. 이 규칙은 Markdown 문서를 일관되고 읽기 쉬우며 유지보수하기 좋게 유지합니다.

## 설정

위에 나열된 설정 키로 이 규칙의 동작을 조정할 수 있습니다.

## 예시

```markdown
* Foo
* Bar
* Baz

1. Foo
1. Bar
1. Baz

1. Foo
   * Bar
1. Baz
```

```markdown
* Foo
* Bar
* Baz
```

```markdown
*   Foo

    Second paragraph

*   Bar
```

```markdown
1.  Foo

    Second paragraph

1.  Bar
```

## 이유

일관된 작성 방식은 읽기와 유지보수 비용을 줄이고 자동화 도구가 문서를 더 안정적으로 처리하게 합니다.
