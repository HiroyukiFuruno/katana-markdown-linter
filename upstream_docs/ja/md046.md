# `MD046` - コードブロックのスタイルを統一してください

タグ: `code`

エイリアス: `code-block-style`

パラメーター:

- `style`: コードブロックのスタイル (`string`, デフォルト `consistent`, 許可値 `fenced`, `indented`, `consistent`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ドキュメント内でフェンス付き（`` ` ``）とインデント形式のコードブロックが混在している場合にトリガーされます。

一貫したスタイルを使用してください。通常は、言語指定が可能なフェンス付きコードブロックが推奨されます。

根拠: スタイルを統一することで、ドキュメントの外観が一貫したものになります。
