# `MD039` - リンクテキストの内側に余分なスペースを入れないでください

タグ: `links`, `spaces`

エイリアス: `no-space-in-links`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、リンクテキストの角括弧（`[]`）の内側にスペースがある場合にトリガーされます。

```markdown
[ リンクテキスト ](https://example.com)
```

これを修正するには、角括弧の内側のスペースを削除してください。

```markdown
[リンクテキスト](https://example.com)
```

根拠: リンクテキストの内側にスペースがあると、一部のパーサーでリンクとして正しく認識されないことがあります。
