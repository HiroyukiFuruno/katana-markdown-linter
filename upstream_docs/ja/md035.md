# `MD035` - 水平線のスタイルを統一してください

タグ: `hr`

エイリアス: `hr-style`

パラメーター:

- `style`: 水平線のスタイル (`string`, デフォルト `consistent`, 許可値 `---`, `***`, その他任意の水平線文字列)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ドキュメント内で異なるスタイルの水平線（Horizontal Rule）が混在している場合にトリガーされます。

```markdown
---

***

- - -
```

ドキュメント全体で統一したスタイルを使用してください。`consistent`（デフォルト）の場合、ドキュメント内の最初の水平線のスタイルに合わせる必要があります。

根拠: 一貫したフォーマットはドキュメントの視覚的な質を向上させます。
