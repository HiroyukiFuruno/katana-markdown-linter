# `MD040` - フェンス付きコードブロックには言語を指定してください

タグ: `code`, `language`

エイリアス: `fenced-code-language`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、フェンス付きコードブロック（`` ` `` または `~~~` で囲まれたもの）に言語指定がない場合にトリガーされます。

```markdown
```
fn main() {}
```
```

これを修正するには、使用しているプログラミング言語を指定してください。

```rust
fn main() {}
```

根拠: 言語を指定することで、ドキュメントの閲覧環境（GitHubやVS Codeなど）において適切なシンタックスハイライトが適用されます。
