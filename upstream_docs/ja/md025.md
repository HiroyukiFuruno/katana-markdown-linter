# `MD025` - 同一文書内のトップレベル見出しは1つにしてください

タグ: `headings`

エイリアス: `single-h1`, `single-title`

パラメーター:

- `front_matter_title`: フロントマター内のタイトルに一致させるための正規表現 (`string`, デフォルト `^\s*title\s*[:=]`)
- `level`: トップレベルとみなす見出しレベル (`integer`, デフォルト `1`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ドキュメント内に複数のトップレベル見出し（デフォルトではレベル1、`#`）がある場合にトリガーされます。

```markdown
# タイトル 1

# タイトル 2
```

通常、トップレベル見出しはドキュメントのタイトルとして1つだけ存在すべきです。2つ目以降の見出しは、レベルを下げるか削除してください。

```markdown
# メインタイトル

## セクション 1
```

根拠: 複数のトップレベル見出しはドキュメントの階層構造を不明確にし、SEOやアクセシビリティの観点からも推奨されません。
