# `MD024` - 同じ内容の見出しが複数あります

タグ: `headings`

エイリアス: `no-duplicate-heading`

パラメーター:

- `siblings_only`: 直接の兄弟見出し間のみをチェックするかどうか (`boolean`, デフォルト `false`)

このルールは、ドキュメント内に全く同じテキストを持つ見出しが複数存在する場合にトリガーされます。

```markdown
# 見出し

## サブセクション

## サブセクション
```

これを修正するには、見出しの内容をユニークなものに変更してください。

```markdown
# 見出し

## 第1サブセクション

## 第2サブセクション
```

`siblings_only` パラメーターを `true` に設定すると、同じ親見出しを持つ兄弟関係にある見出し間での重複のみをチェックします。

根拠: 見出しが重複していると、ドキュメント内でのナビゲーション（特に自動生成される目次やアンカーリンク）が困難になります。
