# `MD028` - 引用ブロック内に不要な空行があります

タグ: `blockquote`

エイリアス: `no-blanks-blockquote`

このルールは、2つの引用ブロックが空行によって隔てられている場合にトリガーされます。

```markdown
> 引用 1

> 引用 2
```

多くの場合、これは1つの引用ブロックとして意図されています。1つのブロックにまとめるか、空行を引用マーカーで埋めてください。

```markdown
> 引用 1
>
> 引用 2
```

根拠: 多くのMarkdownパーサーは、空行で区切られた引用を別々のブロックとしてレンダリングします。これが意図しない表示（余計なマージンなど）につながることがあります。
