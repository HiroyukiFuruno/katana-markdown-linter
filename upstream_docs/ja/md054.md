# `MD054` - リンクと画像のスタイルを設定に合わせてください

タグ: `images`, `links`, `url`

エイリアス: `link-image-style`

パラメーター:

- `autolink`: autolink形式 (`<URL>`) を許可するかどうか (`boolean`, デフォルト `true`)
- `collapsed`: 省略参照形式 (`[text][]`) を許可するかどうか (`boolean`, デフォルト `true`)
- `full`: 完全参照形式 (`[text][label]`) を許可するかどうか (`boolean`, デフォルト `true`)
- `inline`: インライン形式 (`[text](URL)`) を許可するかどうか (`boolean`, デフォルト `true`)
- `shortcut`: ショートカット参照形式 (`[label]`) を許可するかどうか (`boolean`, デフォルト `true`)
- `url_inline`: URLのみのインライン形式を許可するかどうか (`boolean`, デフォルト `true`)

このルールは、リンクや画像の記述スタイルが、設定された許可リストにない場合にトリガーされます。プロジェクトで特定の形式（例: すべて参照形式にする、など）を統一したい場合に使用します。

根拠: ドキュメント全体でリンクの記述スタイルを統一することで、編集の一貫性が保たれます。
