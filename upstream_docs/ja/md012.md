# `MD012` - 複数の連続した空行を削減してください

タグ: `blank_lines`, `whitespace`

エイリアス: `no-multiple-blanks`

パラメーター:

- `maximum`: 許容される連続空行数 (`integer`, デフォルト `1`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ドキュメント内に複数の連続した空行がある場合にトリガーされます。

```markdown
テキスト


さらにテキスト
```

これを修正するには、不要な空行を削除してください。

```markdown
テキスト

さらにテキスト
```

注: コードブロック内の複数の連続した空行については、このルールはトリガーされません。

注: `maximum` パラメーターを使用して、許容する連続空行の最大数を設定できます。

根拠: コードブロック内を除き、空行はそれ自体に目的がなく、コンテンツのレンダリングにも影響を与えません。
