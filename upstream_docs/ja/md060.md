# `MD060` - 表セルのスペースを揃えてください

タグ: `table`

エイリアス: `table-column-style`

パラメーター:

- `aligned_delimiter`: 区切り行を揃えるかどうか (`boolean`, デフォルト `false`)
- `style`: 配置スタイル (`string`, デフォルト `any`, 許可値 `aligned`, `any`, `compact`, `tight`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、表（テーブル）の各セル内の余白（スペース）の使い方が、設定されたスタイルと一致しない場合にトリガーされます。

根拠: セル内のスペースを一貫させることで、ソースコード上のテーブルが整然とし、読みやすくなります。
