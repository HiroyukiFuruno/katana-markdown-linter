# `MD051` - リンク先の見出しフラグメントが存在しません

タグ: `links`

エイリアス: `link-fragments`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、同じドキュメント内の見出しを指すリンクフラグメント（`[text](#heading)`）において、対応する見出しが存在しない場合にトリガーされます。

```markdown
[詳細はこちら](#detials)

## 詳細 (Details)
```

これを修正するには、リンク先のフラグメントを見出しから生成される正しいIDに変更してください。

根拠: 存在しないフラグメントへのリンクは機能せず、ユーザー体験を損ないます。
