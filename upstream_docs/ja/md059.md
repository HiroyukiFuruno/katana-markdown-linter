# `MD059` - リンクテキストは説明的にしてください

タグ: `links`

エイリアス: `descriptive-link-text`

このルールは、リンクテキストが「ここをクリック」や「こちら」といった非説明的な言葉だけである場合にトリガーされます。

```markdown
詳細は [こちら](#details) をご覧ください。
```

これを修正するには、リンク先の内容がわかるような具体的なテキストを使用してください。

```markdown
[詳細な仕様ドキュメント](#details) をご覧ください。
```

根拠: 説明的なリンクテキストは、アクセシビリティ（スクリーンリーダー使用者がリンクの一覧を聞いた際の内容把握）やSEOの観点から非常に重要です。
