# `MD043` - 必要な見出し構造に合わせてください

タグ: `headings`

エイリアス: `required-headings`

パラメーター:

- `headings`: 期待される見出し構造のリスト (`string[]`, デフォルト `[]`)

このルールは、ドキュメント内の見出しが、設定された特定の構造と一致しない場合にトリガーされます。

例えば、`["# タイトル", "## 概要", "## 詳細"]` と設定されている場合、ドキュメントはこれと同じ順序でこれらの見出しを持っている必要があります。

根拠: ドキュメントの形式を統一したい場合（プロジェクトのドキュメントやテンプレートなど）に、特定の構造を強制できます。
