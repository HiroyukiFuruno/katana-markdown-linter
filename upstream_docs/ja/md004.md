# `MD004` - 箇条書きリストの記号スタイルを統一してください

タグ: `bullet`, `ul`

エイリアス: `ul-style`

パラメーター:

- `style`: リストの記号スタイル (`string`, デフォルト `consistent`, 許可値 `asterisk` / `consistent` / `dash` / `plus` / `sublist`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ドキュメント内の箇条書き（非順序）リストで使用されている記号が、設定されたスタイルと一致しない場合にトリガーされます。

```markdown
* 項目 1
+ 項目 2
- 項目 3
```

この問題を修正するには、ドキュメント全体で設定された記号スタイルを使用してください。

```markdown
* 項目 1
* 項目 2
* 項目 3
```

リストの記号スタイル設定では、特定の記号（`asterisk` (*), `plus` (+), `dash` (-)）を強制したり、各階層のサブリストで親リストとは異なる一貫した記号を使用させたり（`sublist`）、最初のリストの記号に合わせる（`consistent`）ことができます。

例えば、`sublist` スタイルの場合、以下のような階層構造は有効です（外側が `*`、中間が `+`、内側が `-`）。

```markdown
* 項目 1
  + 項目 2
    - 項目 3
  + 項目 4
* 項目 4
  + 項目 5
```

根拠: 一貫したフォーマットはドキュメントの理解を助けます。
