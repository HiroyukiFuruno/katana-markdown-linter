# `MD048` - フェンス付きコードブロックの記号スタイルを統一してください

タグ: `code`

エイリアス: `code-fence-style`

パラメーター:

- `style`: 使用する記号 (`string`, デフォルト `consistent`, 許可値 `backtick`, `tilde`, `consistent`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、フェンス付きコードブロックで使用される記号（`` ` `` または `~~~`）が、設定されたスタイルと一致しない、またはドキュメント内で混在している場合にトリガーされます。

根拠: 一貫した記号の使用は、ソースコードの見た目を整えます。
