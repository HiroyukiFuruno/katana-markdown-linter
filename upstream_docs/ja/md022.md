# `MD022` - 見出しは空行で囲んでください

タグ: `blank_lines`, `headings`

エイリアス: `blanks-around-headings`

パラメーター:

- `lines_above`: 見出しの上の空行数 (`integer`, デフォルト `1`)
- `lines_below`: 見出しの下の空行数 (`integer`, デフォルト `1`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、見出しの前後（上または下）に空行がない場合にトリガーされます。

```markdown
# 見出し 1
本文
```

これを修正するには、見出しの周りに空行を追加してください。

```markdown
# 見出し 1

本文
```

注: 連続する見出しの間にも空行が必要です。

根拠: 見出しの周りに空行を置くことで、ドキュメントの構造が視覚的に明確になり、一部のパーサーでの誤認を防ぐことができます。
