# `MD007` - 箇条書きリストのインデントを設定に合わせてください

タグ: `bullet`, `indentation`, `ul`

エイリアス: `ul-indent`

パラメーター:

- `indent`: インデントのスペース数 (`integer`, デフォルト `2`)
- `start_indent`: 第1レベルのインデントスペース数（`start_indented` が設定されている場合） (`integer`, デフォルト `2`)
- `start_indented`: リストの第1レベルをインデントするかどうか (`boolean`, デフォルト `false`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、リスト項目が設定されたスペース数（デフォルトは2）でインデントされていない場合にトリガーされます。

例:

```markdown
* リスト項目
   * 3スペースでインデントされた入れ子項目
```

修正例:

```markdown
* リスト項目
  * 2スペースでインデントされた入れ子項目
```

注: このルールは、親リストがすべて箇条書き（非順序）リストであるサブリストにのみ適用されます（順序付きリストのインデントがこのルールと干渉するのを避けるためです）。

`start_indented` パラメーターを有効にすると、リストの第1レベルを開始位置（0）ではなく設定されたスペース数だけインデントすることができます。`start_indent` パラメーターを使用すると、第1レベルのインデント量を他のレベルとは異なる値に設定できます（`start_indented` が設定されていない場合は無視されます）。

根拠: 2スペースのインデントを使用すると、リストマーカーの後に1つのスペースを入れた場合に、入れ子リストのコンテンツが親リストのコンテンツの開始位置と揃います。4スペースのインデントはコードブロックと一貫性があり、エディターでの実装が容易です。また、他のMarkdownパーサー（4スペースインデントを要求するもの）との互換性のために必要になることもあります。詳細情報: [Markdown Style Guide][markdown-style-guide].

注: 互換性情報については [Prettier.md](Prettier.md) を参照してください。

[markdown-style-guide]: https://cirosantilli.com/markdown-style-guide#indentation-of-content-inside-lists
