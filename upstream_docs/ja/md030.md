# `MD030` - リスト記号後のスペース数を揃えてください

タグ: `ol`, `spaces`, `ul`

エイリアス: `list-marker-space`

パラメーター:

- `ul_single`: 単一行の箇条書きリスト後のスペース数 (`integer`, デフォルト `1`)
- `ol_single`: 単一行の番号付きリスト後のスペース数 (`integer`, デフォルト `1`)
- `ul_multi`: 複数行の箇条書きリスト後のスペース数 (`integer`, デフォルト `1`)
- `ol_multi`: 複数行の番号付きリスト後のスペース数 (`integer`, デフォルト `1`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、リストマーカー（`*`, `-`, `+`, `1.` など）の後のスペースの数が、設定と一致しない場合にトリガーされます。

```markdown
*   項目 1
* 項目 2
```

通常は1つのスペースを使用するように統一します。

```markdown
* 項目 1
* 項目 2
```

根拠: リスト内の余分なスペースは、視覚的な一貫性を損なう可能性があります。
