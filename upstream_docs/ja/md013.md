# `MD013` - 行の長さが上限を超えています

タグ: `line_length`

エイリアス: `line-length`

パラメーター:

- `code_block_line_length`: コードブロックの文字数制限 (`integer`, デフォルト `80`)
- `code_blocks`: コードブロックを含めるかどうか (`boolean`, デフォルト `true`)
- `heading_line_length`: 見出しの文字数制限 (`integer`, デフォルト `80`)
- `headings`: 見出しを含めるかどうか (`boolean`, デフォルト `true`)
- `line_length`: 1行の最大文字数 (`integer`, デフォルト `80`)
- `stern`: Stern（厳格寄り）な長さチェックを行うかどうか (`boolean`, デフォルト `false`)
- `strict`: 厳格な長さチェックを行うかどうか (`boolean`, デフォルト `false`)
- `tables`: テーブルを含めるかどうか (`boolean`, デフォルト `true`)

このルールは、設定された `line_length`（デフォルト：80文字）よりも長い行がある場合にトリガーされます。修正するには、1行を複数の行に分割してください。見出しに異なる最大長を設定するには `heading_line_length` を、コードブロックに設定するには `code_block_line_length` を使用します。

このルールには、設定された行の長さを超えた部分に空白（スペース）がない場合の例外があります。これにより、長いURLなどを途中で強制的に分割することなく含めることができます。この例外を無効にして、いかなる場合でも行が長すぎる場合に報告するには、`strict` パラメーターを `true` に設定してください。スペースのない長い行は許容しつつ、修正可能な（スペースを含む）長い行に対して警告を出すには、`stern` パラメーターを `true` に設定します。

例（通常動作の場合）:

```markdown
IF THIS LINE IS THE MAXIMUM LENGTH
This line is okay because there are-no-spaces-beyond-that-length
This line is a violation because there are spaces beyond that length
This-line-is-okay-because-there-are-no-spaces-anywhere-within
```

`strict` モードでは、上の最後の3行はすべて違反になります。`stern` モードでは、真ん中の2行が違反になり、最後の行は許可されます。

コードブロック、テーブル、見出しをこのルールの対象外に設定することもできます。その場合は、`code_blocks`、`tables`、`headings` パラメーターを `false` に設定してください。

コードブロックは、ドキュメントの可読性の観点からデフォルトで検査対象に含まれています。ただし、一部のプログラミング言語では短い行に分割するのが難しい場合があります。

リンクや画像の参照定義行、およびリンクや画像のみを含む独立した行（パラグラフの一部ではないもの、強調が含まれていても良い）は、URLを壊さずに分割する方法がないことが多いため、常にこのルールから除外されます（`strict` モードでも同様です）。

根拠: 極端に長い行は、一部のエディターで扱いにくい場合があります。詳細情報: <https://cirosantilli.com/markdown-style-guide#line-wrapping>
