# `MD023` - 見出しは行頭から始めてください

タグ: `headings`, `indentation`, `spaces`

エイリアス: `heading-start-left`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、見出しがインデント（行頭のスペース）されている場合にトリガーされます。

```markdown
  # インデントされた見出し
```

これを修正するには、見出しの前のスペースを削除してください。

```markdown
# 行頭から始まる見出し
```

根拠: 見出しをインデントすると、一部のパーサーでコードブロックとして誤認されたり、一貫性のない表示になったりする可能性があります。
