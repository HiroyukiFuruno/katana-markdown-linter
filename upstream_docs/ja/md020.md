# `MD020` - 閉じた ATX 形式の見出しの内側にスペースが必要です

タグ: `atx_closed`, `headings`, `spaces`

エイリアス: `no-missing-space-closed-atx`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、閉じた ATX 形式の見出しにおいて、シャープ記号（#）の内側にスペースがない場合にトリガーされます。

```markdown
#見出し 1#

##見出し 2##
```

これを修正するには、シャープ記号と見出しテキストの間に1つのスペースを入れてください。

```markdown
# 見出し 1 #

## 見出し 2 ##
```

注: 見出しのどちらか一方にスペースが欠けている場合でも、このルールが適用されます。

根拠: このルールに違反すると、コンテンツが正しくレンダリングされない可能性があります。
