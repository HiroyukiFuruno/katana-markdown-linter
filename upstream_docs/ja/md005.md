# `MD005` - 同じレベルのリスト項目のインデントを揃えてください

タグ: `bullet`, `indentation`, `ul`

エイリアス: `list-indent`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、同じ階層レベルにあると解析されるリスト項目が、異なるインデント量を持っている場合にトリガーされます。

```markdown
* 項目 1
  * 入れ子項目 1
  * 入れ子項目 2
   * 位置がずれている項目
```

通常、このルールはタイポ（入力ミス）によって発生します。インデントを正しく調整することで修正できます。

```markdown
* 項目 1
  * 入れ子項目 1
  * 入れ子項目 2
  * 入れ子項目 3
```

順序付きリストのマーカーは、通常、すべての項目の開始列が揃うように左揃えで記述されます。

```markdown
...
8. 項目
9. 項目
10. 項目
11. 項目
...
```

このルールは、マーカーの終了列（ピリオドの位置）が揃うような右揃えの記述もサポートしています。

```markdown
...
 8. 項目
 9. 項目
10. 項目
11. 項目
...
```

根拠: このルールに違反すると、ドキュメントが正しくレンダリングされない可能性があります。
