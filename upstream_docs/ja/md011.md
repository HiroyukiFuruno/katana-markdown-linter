# `MD011` - 逆向きのリンク構文を修正してください

タグ: `links`

エイリアス: `no-reversed-links`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、リンクのように見えるテキストが、`[]` と `()` の位置が逆になっている構文で記述されている場合にトリガーされます。

```markdown
(不正なリンク構文)[https://www.example.com/]
```

これを修正するには、`[]` と `()` を入れ替えてください。

```markdown
[正しいリンク構文](https://www.example.com/)
```

注: [Markdown Extra](https://en.wikipedia.org/wiki/Markdown_Extra) 形式の脚注はこのルールの対象外です。

```markdown
例: (example)[^1]
```

根拠: 逆向きのリンクは、有効なリンクとしてレンダリングされません。
