# `MD037` - 強調記号の内側にスペースを入れないでください

タグ: `emphasis`, `spaces`

エイリアス: `no-space-in-emphasis`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、強調マーカー（`*` または `_`）の直後にスペースがある場合、または強調マーカーの直前にスペースがある場合にトリガーされます。

```markdown
これは * 強調 * です。
```

これを修正するには、強調記号の内側のスペースを削除してください。

```markdown
これは *強調* です。
```

根拠: 強調記号の内側にスペースがあると、一部のパーサーで強調として正しく認識されないことがあります。
