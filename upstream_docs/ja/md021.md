# `MD021` - 閉じた ATX 形式の見出しの内側のスペースは1つにしてください

タグ: `atx_closed`, `headings`, `spaces`

エイリアス: `no-multiple-space-closed-atx`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、閉じた ATX 形式の見出しにおいて、シャープ記号（#）と見出しテキストの間に2つ以上のスペースが使用されている場合にトリガーされます。

```markdown
#  見出し 1  #

##  見出し 2  ##
```

これを修正するには、シャープ記号と見出しテキストの間のスペースを1つにしてください。

```markdown
# 見出し 1 #

## 見出し 2 ##
```

根拠: 余分なスペースには目的がなく、コンテンツのレンダリングにも影響しません。
