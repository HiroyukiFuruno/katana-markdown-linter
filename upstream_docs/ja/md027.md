# `MD027` - 引用記号の後の余分なスペースを削除してください

タグ: `blockquote`, `indentation`, `spaces`

エイリアス: `no-multiple-space-blockquote`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、引用マーカー（`>`）の後に複数のスペースが使用されている場合にトリガーされます。

```markdown
>  引用文
```

通常、引用マーカーの後には1つのスペースを入れるか、またはスペースを入れないのが一般的です。余分なスペースを削除してください。

```markdown
> 引用文
```

根拠: 余分なスペースはコンテンツのレンダリングに寄与せず、ソースコードの一貫性を損ないます。
