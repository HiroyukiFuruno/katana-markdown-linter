# `MD031` - コードブロックは空行で囲んでください

タグ: `blank_lines`, `code`

エイリアス: `blanks-around-fences`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、フェンス付きコードブロック（`` ` `` で囲まれたもの）の前後（上または下）に空行がない場合にトリガーされます。

```markdown
テキスト
```rust
fn main() {}
```
本文
```

これを修正するには、コードブロックの周りに空行を追加してください。

```markdown
テキスト

```rust
fn main() {}
```

本文
```

根拠: コードブロックの周りに空行を置かないと、一部のパーサーでコードブロックとして正しく認識されないことがあります。
