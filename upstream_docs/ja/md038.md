# `MD038` - コード記号の内側にスペースを入れないでください

タグ: `code`, `spaces`

エイリアス: `no-space-in-code`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、インラインコード（`` ` ``）の直後にスペースがある場合、または直前にスペースがある場合にトリガーされます。

```markdown
これは ` code ` です。
```

これを修正するには、バッククォートの内側のスペースを削除してください。

```markdown
これは `code` です。
```

注: バッククォート自体をコード内に含めるためにスペースが必要な場合（例: `` ` `` ` `` ` ``）は、このルールは適用されません。

根拠: バッククォートの内側にスペースがあると、コードとして認識されないパーサーがあったり、不要な空白が表示に含まれたりします。
