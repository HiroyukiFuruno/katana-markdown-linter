# `MD003` - 見出しのスタイルを統一してください

タグ: `headings`

エイリアス: `heading-style`

パラメーター:

- `style`: 見出しのスタイル (`string`, デフォルト `consistent`, 許可値 `atx` / `atx_closed` / `consistent` / `setext` / `setext_with_atx` / `setext_with_atx_closed`)

このルールは、同じドキュメント内で異なる見出しスタイルが混在している場合にトリガーされます。

```markdown
# ATX形式の見出し1

## 閉じたATX形式の見出し2 ##

Setext形式の見出し1
===============
```

この問題を修正するには、ドキュメント全体で統一した見出しスタイルを使用してください。

```markdown
# ATX形式の見出し1

## ATX形式の見出し2
```

`setext_with_atx` および `setext_with_atx_closed` 設定を使用すると、Setext形式（レベル1と2のみサポート）を採用しているドキュメントにおいて、レベル3以上の見出しにATX形式を使用することが許可されます。

```markdown
Setext形式の見出し1
===============

Setext形式の見出し2
---------------

### ATX形式の見出し3
```

注: 設定可能な見出しスタイルには、特定のスタイルを強制するもの（`atx`, `atx_closed`, `setext`, `setext_with_atx`, `setext_with_atx_closed`）と、最初の見出しのスタイルに合わせる `consistent` があります。

注: テキスト行の直下に水平線を配置すると、そのテキストがレベル2のSetext形式の見出しとして解釈され、このルールがトリガーされることがあります。

```markdown
テキスト行の後に水平線が続くと、見出しになります
---
```

根拠: 一貫したフォーマットはドキュメントの理解を助けます。
