# `MD041` - ファイルの最初の行はトップレベル見出しにしてください

タグ: `headings`

エイリアス: `first-line-heading`, `first-line-h1`

パラメーター:

- `front_matter_title`: フロントマター内のタイトルに一致させるための正規表現 (`string`, デフォルト `^\s*title\s*[:=]`)
- `level`: 期待される見出しレベル (`integer`, デフォルト `1`)

このルールは、ドキュメントの最初の非空行が見出し（デフォルトではレベル1、`#`）でない場合にトリガーされます。

```markdown
このドキュメントの導入文...

# タイトル
```

ドキュメントの最初は、その内容を示すトップレベルの見出しから始めるのが一般的です。

```markdown
# ドキュメントタイトル

このドキュメントの導入文...
```

根拠: 最初に適切な見出しがあることで、読者や検索エンジン、スクリーンリーダーがドキュメントの主題を即座に把握できます。
