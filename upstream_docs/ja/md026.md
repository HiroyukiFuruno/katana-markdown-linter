# `MD026` - 見出し末尾の句読点を削除してください

タグ: `headings`

エイリアス: `no-trailing-punctuation`

パラメーター:

- `punctuation`: 句読点として扱う文字のリスト (`string`, デフォルト `.,;:!?。、；：！？`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、見出しの末尾に句読点が含まれている場合にトリガーされます。

```markdown
# これは見出しです。
```

これを修正するには、末尾の句読点を削除してください。

```markdown
# これは見出しです
```

根拠: 見出しは文ではないため、末尾に句読点を付ける必要はありません。視覚的にも句読点がないほうがスッキリします。
