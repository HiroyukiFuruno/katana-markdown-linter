# `MD018` - ATX形式の見出しの # の後にスペースが必要です

タグ: `atx`, `headings`, `spaces`

エイリアス: `no-missing-space-atx`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、ATX形式の見出しにおいて、シャープ記号（#）の後にスペースがない場合にトリガーされます。

```markdown
#見出し 1

##見出し 2
```

これを修正するには、シャープ記号と見出しテキストの間に1つのスペースを入れてください。

```markdown
# 見出し 1

## 見出し 2
```

根拠: このルールに違反すると、コンテンツが正しくレンダリングされない可能性があります。
