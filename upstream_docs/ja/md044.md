# `MD044` - 固有名詞の表記を設定に合わせてください

タグ: `proper_names`, `spelling`

エイリアス: `proper-names`

パラメーター:

- `code_blocks`: コードブロック内もチェックするかどうか (`boolean`, デフォルト `true`)
- `names`: 期待される固有名詞のリスト (`string[]`, デフォルト `[]`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、設定された固有名詞のリスト（大文字小文字を区別）と異なる表記がある場合にトリガーされます。

例えば、`names` に `["JavaScript"]` が設定されている場合、本文中に `javascript` とあると報告されます。

根拠: 技術用語や固有名詞の表記を統一することで、ドキュメントの専門性と信頼性が向上します。
