# `MD045` - 画像には代替テキストを設定してください

タグ: `accessibility`, `images`

エイリアス: `no-alt-text`

このルールは、画像（`![]()`）の代替テキスト（角括弧内のテキスト）が空の場合にトリガーされます。

```markdown
![](image.png)
```

これを修正するには、画像の内容を説明する短いテキストを入力してください。

```markdown
![ロゴ画像](image.png)
```

根拠: 代替テキストは、画像が表示されない環境や、視覚障害者がスクリーンリーダーを使用する際に、画像の内容を伝えるために不可欠です（アクセシビリティの向上）。
