# `MD001` - 見出しレベルは一度に1段階ずつ増やしてください

タグ: `headings`

エイリアス: `heading-increment`

パラメーター:

- `front_matter_title`: フロントマター内のタイトルに一致させるための正規表現 (`string`, デフォルト `^\s*title\s*[:=]`)

このルールは、Markdownドキュメントで見出しレベルをスキップした場合にトリガーされます。例:

```markdown
# 見出し 1

### 見出し 3

このドキュメントでは第2レベルの見出しをスキップしました
```

複数の見出しレベルを使用する場合、入れ子になった見出しは一度に1レベルずつ増やす必要があります。

```markdown
# 見出し 1

## 見出し 2

### 見出し 3

#### 見出し 4

## 別の見出し 2

### 別の見出し 3
```

[YAML](https://en.wikipedia.org/wiki/YAML) フロントマターが存在し、`title` プロパティ（ブログ投稿などで一般的）が含まれている場合、このルールはそれをトップレベルの見出しとして扱い、実際の最初の見出しがレベル2の見出しでない場合に違反を報告します。フロントマターで別のプロパティ名を使用するには、`front_matter_title` パラメーターを介して正規表現のテキストを指定します。このルールによるフロントマターの使用を無効にするには、`front_matter_title` に `""` を指定します。フロントマターが存在しない場合、最初の見出しは任意のレベルにすることができます。

根拠: 見出しはドキュメントの構造を表しており、スキップされると混乱を招く可能性があります（特にアクセシビリティの観点から）。詳細情報: <https://www.w3.org/WAI/tutorials/page-structure/headings/>
