# `MD029` - 番号付きリストの番号を正しく並べてください

タグ: `ol`

エイリアス: `ol-prefix`

パラメーター:

- `style`: 番号のスタイル (`string`, デフォルト `one_or_ordered`, 許可値 `one`, `ordered`, `one_or_ordered`, `zero`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、順序付き（番号付き）リストの番号が、設定されたスタイルに従っていない場合にトリガーされます。

デフォルトの `one_or_ordered` スタイルでは、すべての項目を `1.` にするか、または `1., 2., 3., ...` と昇順にする必要があります。

```markdown
1. 項目 1
1. 項目 2
```
または
```markdown
1. 項目 1
2. 項目 2
```

スタイルを `one` に設定すると、すべての項目を `1.` で始める必要があります（パーサーが自動的に番号を振るため、管理が容易になります）。`ordered` に設定すると、常に `1., 2., 3., ...` と記述する必要があります。

根拠: 一貫したリスト番号の記述は、ドキュメントの編集とメンテナンスを容易にします。
