# `MD033` - インライン HTML を使用しないでください

タグ: `html`

エイリアス: `no-inline-html`

パラメーター:

- `allowed_elements`: 許可されるHTML要素のリスト (`string[]`, デフォルト `[]`)

このルールは、Markdownドキュメント内でインラインHTML（`<tag>...</tag>`）が使用されている場合にトリガーされます。

```markdown
<center>中央揃え</center>
```

Markdownの標準的な構文（強調、リンク、画像など）を使用できる場合は、そちらを優先してください。どうしてもHTMLが必要な要素がある場合は、`allowed_elements` パラメーターでそのタグを許可リストに追加できます。

根拠: Markdownの目的は、プレーンテキストとしての読みやすさを維持することです。HTMLが混在すると、ソースコードの可読性が低下します。
