# `MD036` - 強調だけの行を見出しとして使用しないでください

タグ: `emphasis`, `headings`

エイリアス: `no-emphasis-as-heading`

パラメーター:

- `punctuation`: 文末記号として扱う文字のリスト (`string`, デフォルト `.,;:!?。、；：！？`)

このルールは、単一行が強調（太字や斜体）だけで構成され、その直後に本文が続いている場合にトリガーされます。これは通常、見出し構文（`#`）の代わりに見出しを模倣しようとしていることを示唆します。

```markdown
**セクションタイトル**

このセクションの内容...
```

これを修正するには、適切な見出しレベルのシャープ記号（`#`）を使用してください。

```markdown
## セクションタイトル

このセクションの内容...
```

根拠: 見出し構文を使用することで、ドキュメントの構造がプログラム（スクリーンリーダーや目次生成ツールなど）から正しく認識できるようになります。
