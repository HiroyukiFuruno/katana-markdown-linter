# `MD049` - 強調のスタイルを統一してください

タグ: `emphasis`

エイリアス: `emphasis-style`

パラメーター:

- `style`: 使用する記号 (`string`, デフォルト `consistent`, 許可値 `asterisk`, `consistent`, `underscore`)

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、強調（斜体）で使用される記号（`*` または `_`）が、設定されたスタイルと一致しない、またはドキュメント内で混在している場合にトリガーされます。

根拠: 一貫したスタイルの適用は、ドキュメントの視覚的な一貫性を保ちます。
