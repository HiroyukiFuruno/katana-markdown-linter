# `MD032` - リストは空行で囲んでください

タグ: `blank_lines`, `indentation`, `ol`, `ul`

エイリアス: `blanks-around-lists`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、リストの前後（上または下）に空行がない場合にトリガーされます。

```markdown
テキスト
- リスト項目
本文
```

これを修正するには、リストの周りに空行を追加してください。

```markdown
テキスト

- リスト項目

本文
```

根拠: リストの周りに空行を置かないと、一部のパーサーでリストとして正しく認識されなかったり、直前の段落の一部としてレンダリングされたりすることがあります。
