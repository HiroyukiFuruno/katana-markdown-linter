# `MD014` - コマンド例の前に不要なドル記号があります

タグ: `code`

エイリアス: `commands-show-output`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、入力するシェルコマンドを示すコードブロックにおいて、*すべて*のコマンドの前にドル記号（$）が付いている場合にトリガーされます。

<!-- markdownlint-disable commands-show-output -->

```markdown
$ ls
$ cat foo
$ less bar
```

<!-- markdownlint-restore -->

このような状況ではドル記号は不要であり、含めるべきではありません。

```markdown
ls
cat foo
less bar
```

ドル記号で始まるコマンドの後にその出力が表示されている場合は、このルールはトリガーされません。

```markdown
$ ls
foo bar
$ cat foo
Hello world
$ cat bar
baz
```

一部のコマンドは出力を生成しないため、*一部*のコマンドに出力がない場合でも違反にはなりません。

```markdown
$ mkdir test
mkdir: created directory 'test'
$ ls test
```

根拠: 不要なドル記号を省略することで、コピー＆ペーストが容易になり、見た目もすっきりします。詳細については、<https://cirosantilli.com/markdown-style-guide#dollar-signs-in-shell-code> を参照してください。
