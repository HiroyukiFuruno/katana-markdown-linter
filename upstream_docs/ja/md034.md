# `MD034` - 裸の URL は山括弧またはリンクとして記述してください

タグ: `links`, `url`

エイリアス: `no-bare-urls`

修正可能性: 一部の違反はツールによって自動修正可能です。

このルールは、山括弧（`<...>`）で囲まれていない、またはリンク構文（`[...] (...)`）になっていないURLが直接記述されている場合にトリガーされます。

```markdown
詳細は https://example.com を参照してください。
```

これを修正するには、URLを山括弧で囲むか、適切なリンクとして記述してください。

```markdown
詳細は <https://example.com> を参照してください。
```

根拠: 裸のURLは、一部のMarkdownパーサーでリンクとして自動認識されないことがあります。山括弧で囲むことで、明示的にURLであることを示し、パースミスを防ぐことができます。
