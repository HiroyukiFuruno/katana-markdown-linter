# `MD059` - Il testo del link deve essere descrittivo

Tag: `accessibility`, `links`

Alias: `descriptive-link-text`

Parametri:

- `prohibited_texts`: valore di configurazione (`string[]`, predefinito `["click here","here","link","more"]`)

## Panoramica

Il testo del link deve essere descrittivo. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

Nessuno.

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
