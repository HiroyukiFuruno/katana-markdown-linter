# `MD045` - Le immagini devono avere testo alternativo

Tag: `accessibility`, `images`

Alias: `no-alt-text`

Parametri:

Nessuno.

## Panoramica

Le immagini devono avere testo alternativo. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
![Alternate text](image.jpg)
```

```markdown
![Alternate text][ref]

...

[ref]: image.jpg "Optional title"
```

```html
<img src="image.jpg" alt="Alternate text" />
```

```html
<img src="image.jpg" aria-hidden="true" />
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
