# `MD018` - I titoli ATX richiedono uno spazio dopo #

Tag: `atx`, `headings`, `spaces`

Alias: `no-missing-space-atx`

Parametri:

Nessuno.

## Panoramica

I titoli ATX richiedono uno spazio dopo #. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
#Heading 1

##Heading 2
```

```markdown
# Heading 1

## Heading 2
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
