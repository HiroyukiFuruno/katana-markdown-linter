# `MD053` - Sono presenti definizioni di link non usate

Tag: `images`, `links`

Alias: `link-image-reference-definitions`

Parametri:

- `ignored_definitions`: valore di configurazione (`string[]`, predefinito `["//"]`)

## Panoramica

Sono presenti definizioni di link non usate. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
[//]: # (This behaves like a comment)
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
