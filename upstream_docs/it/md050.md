# `MD050` - Mantieni uno stile di enfasi forte coerente

Tag: `emphasis`

Alias: `strong-style`

Parametri:

- `style`: valore di configurazione (`string`, predefinito `consistent`)

## Panoramica

Mantieni uno stile di enfasi forte coerente. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
**Text**
__Text__
```

```markdown
**Text**
**Text**
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
