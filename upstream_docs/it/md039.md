# `MD039` - Rimuovi spazi superflui dentro il testo del link

Tag: `links`, `whitespace`

Alias: `no-space-in-links`

Parametri:

Nessuno.

## Panoramica

Rimuovi spazi superflui dentro il testo del link. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
[ a link ](https://www.example.com/)
```

```markdown
[a link](https://www.example.com/)
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
