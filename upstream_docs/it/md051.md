# `MD051` - Il frammento di titolo collegato non esiste

Tag: `links`

Alias: `link-fragments`

Parametri:

- `ignore_case`: valore di configurazione (`boolean`, predefinito `false`)
- `ignored_pattern`: valore di configurazione (`string`, predefinito ``)

## Panoramica

Il frammento di titolo collegato non esiste. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
# Heading Name

[Link](#fragment)
```

```markdown
# Heading Name

[Link](#heading-name)
```

```markdown
# Heading Name

[Link](#Heading-Name)
```

```markdown
# Heading Name {#custom-name}

[Link](#custom-name)
```

```markdown
<a id="bookmark"></a>

[Link](#bookmark)
```

```markdown
[Link](#top)
```

```markdown
[Link](#L20)
```

```markdown
[Link](#L19C5-L21C11)
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
