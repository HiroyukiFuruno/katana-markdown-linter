# `MD020` - I titoli ATX chiusi richiedono spazi interni

Tag: `atx_closed`, `headings`, `spaces`

Alias: `no-missing-space-closed-atx`

Parametri:

Nessuno.

## Panoramica

I titoli ATX chiusi richiedono spazi interni. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
#Heading 1#

##Heading 2##
```

```markdown
# Heading 1 #

## Heading 2 ##
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
