# `MD047` - I file devono terminare con un ritorno a capo

Tag: `blank_lines`

Alias: `single-trailing-newline`

Parametri:

Nessuno.

## Panoramica

I file devono terminare con un ritorno a capo. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
# Heading

This file ends without a newline.[EOF]
```

```markdown
# Heading

This file ends with a newline.
[EOF]
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
