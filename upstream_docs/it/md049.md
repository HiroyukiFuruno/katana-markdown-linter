# `MD049` - Mantieni uno stile di enfasi coerente

Tag: `emphasis`

Alias: `emphasis-style`

Parametri:

- `style`: valore di configurazione (`string`, predefinito `consistent`)

## Panoramica

Mantieni uno stile di enfasi coerente. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```markdown
*Text*
_Text_
```

```markdown
*Text*
*Text*
```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
