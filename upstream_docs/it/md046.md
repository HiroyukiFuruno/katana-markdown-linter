# `MD046` - Mantieni uno stile coerente per i blocchi di codice

Tag: `code`

Alias: `code-block-style`

Parametri:

- `style`: valore di configurazione (`string`, predefinito `consistent`)

## Panoramica

Mantieni uno stile coerente per i blocchi di codice. Questa regola aiuta a mantenere i documenti Markdown coerenti, leggibili e facili da mantenere.

## Configurazione

Usa le chiavi di configurazione elencate sopra per regolare il comportamento di questa regola.

## Esempi

```ruby
    # Fenced code
    ```

## Motivo

Una scrittura coerente riduce il costo di lettura e manutenzione e rende l'automazione più affidabile.
