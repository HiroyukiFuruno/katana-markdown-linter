# `MD044` - Escribe los nombres propios según la configuración

Etiquetas: `spelling`

Alias: `proper-names`

Parámetros:

- `code_blocks`: valor de configuración (`boolean`, predeterminado `true`)
- `html_elements`: valor de configuración (`boolean`, predeterminado `true`)
- `names`: valor de configuración (`string[]`, predeterminado `[]`)

## Resumen

Escribe los nombres propios según la configuración. Esta regla ayuda a mantener los documentos Markdown coherentes, legibles y fáciles de mantener.

## Configuración

Usa las claves de configuración anteriores para ajustar el comportamiento de esta regla.

## Ejemplos

```json
[
    "JavaScript"
]
```

```json
[
    "GitHub",
    "github.com"
]
```

## Motivo

Una escritura coherente reduce el coste de lectura y mantenimiento y hace que la automatización sea más fiable.
