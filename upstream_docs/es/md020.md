# `MD020` - Los encabezados ATX cerrados necesitan espacios internos

Etiquetas: `atx_closed`, `headings`, `spaces`

Alias: `no-missing-space-closed-atx`

Parámetros:

Ninguno.

## Resumen

Los encabezados ATX cerrados necesitan espacios internos. Esta regla ayuda a mantener los documentos Markdown coherentes, legibles y fáciles de mantener.

## Configuración

Usa las claves de configuración anteriores para ajustar el comportamiento de esta regla.

## Ejemplos

```markdown
#Heading 1#

##Heading 2##
```

```markdown
# Heading 1 #

## Heading 2 ##
```

## Motivo

Una escritura coherente reduce el coste de lectura y mantenimiento y hace que la automatización sea más fiable.
